REST-API

Skripte und andere Systeme lesen über eine JSON-API Geräte, Prüfungen, Diagramme und Probleme, bestätigen Probleme und planen Wartungen.

Tokens

Legen Sie unter Mein Konto → API-Token ein Token an: einen Namen und wie viele Tage es gültig ist. Es wird einmal angezeigt. Ein Token handelt in Ihrem Namen, mit Ihrer Rolle (das Token eines Betrachters kann nur lesen); widerrufen Sie es, wenn es nicht mehr gebraucht wird. Fehlgeschlagene Tokens zählen wie fehlgeschlagene Anmeldungen und sperren die Adresse für eine Weile.

Senden Sie es in einem Header; die API akzeptiert nie das Sitzungscookie der Konsole:

curl -H "Authorization: Bearer wzat_…" https://monitor.example.com:8443/api/v1/status

Zeiten sind im Format RFC 3339 (2026-11-01T22:00:00+01:00). Fehler haben die Form {"error": "…"} mit einem passenden HTTP-Status. Änderungen werden mit dem Namen des Tokens in das Prüfprotokoll geschrieben.
