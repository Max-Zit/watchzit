Server installieren

WatchZit läuft auf einem 64-Bit-Linux-Server (eine kleine virtuelle Maschine genügt) mit PostgreSQL. Das Installationsskript richtet alles ein; Pakete und ein fertiges Appliance-Image gibt es ebenfalls.

Voraussetzungen

  • Debian 12+, Ubuntu 22.04+, AlmaLinux oder Rocky Linux 9+, x86-64.
  • 2 CPU-Kerne und 2 GB Arbeitsspeicher für einige hundert Geräte; 10 GB Festplattenplatz (Messwerte werden kompakt gespeichert: eine Stunde Ping-Zeiten belegt etwa 100 Byte).
  • Ports: 8443 für die Konsole (Ihre Administrationsnetze), 8444 für Agenten (nur dort, wo Agenten sind).

Installationsskript

Als root auf dem Server:

curl -fsSL https://github.com/Max-Zit/watchzit/releases/latest/download/install.sh | sudo sh

Das Skript installiert PostgreSQL, lädt die neueste Version herunter, prüft ihre Signatur mit dem WatchZit-Release-Schlüssel, installiert das Paket, legt die Datenbank mit einem zufälligen Passwort an, öffnet die Ports in firewalld oder ufw und startet den Dienst. Am Ende gibt es die Konsolenadresse und das Einrichtungstoken aus.

Optionen: --version X (eine bestimmte Version), --db postgres://… (eine vorhandene Datenbank statt eines lokalen PostgreSQL), --no-auto-updates (die Sicherheitsupdates des Betriebssystems nicht einschalten), --source URL (ein Spiegelserver oder ein lokaler Ordner mit den Release-Dateien). Wenn Sie das Skript erneut ausführen, wird WatchZit aktualisiert und die Daten bleiben erhalten.

Pakete

Jede Version enthält ein .deb- und ein .rpm-Paket des Servers. Sie installieren das Programm, die systemd-Dienste und die Agenten-Installationsprogramme; setzen Sie WATCHZIT_DB in /etc/watchzit/server.env und starten Sie watchzit-server.

Appliance

Die Appliance ist ein fertiges Image (Debian mit WatchZit, PostgreSQL und automatischen Sicherheitsupdates). Importieren Sie es in VMware, Proxmox oder Hyper-V, starten Sie es und folgen Sie dem Menü auf dem Bildschirm: Es zeigt die Konsolenadresse und das Einrichtungstoken und richtet das Netzwerk ein.

Images: OVA (VMware ESXi, Workstation, VirtualBox), qcow2 (Proxmox, KVM), VHDX (Hyper-V Generation 1) und ein ISO, das die Appliance auf einer neuen VM oder einem physischen Server installiert (es löscht die erste Festplatte). Geben Sie ihr 2 CPUs, 2 GB Arbeitsspeicher und eine Festplatte mit 16 GB oder mehr; eine größere Festplatte wird automatisch genutzt. Melden Sie sich am Bildschirm als wzadmin mit dem Erstpasswort watchzit an; Sie müssen sofort ein neues wählen. Das Menü legt das Netzwerk (DHCP oder eine feste Adresse), den Servernamen, die Zeitzone und SSH (ein oder aus, Port) fest und setzt ein neues Passwort für einen Konsolenbenutzer wie admin (und hebt dabei alle Anmeldesperren auf). Netzwerk, SSH, Betriebssystem-Updates und ein vertrauenswürdiges Zertifikat lassen sich auch in der Konsole einstellen (siehe Benutzer, Einstellungen und Updates). SSH erlaubt keine Anmeldung als root.

Erste Anmeldung

  1. Öffnen Sie https://<server>:8443. Der Browser warnt einmal vor dem selbstsignierten Zertifikat; akzeptieren Sie es.
  2. Geben Sie das Einrichtungstoken ein und legen Sie den ersten Administrator an.
  3. Scannen Sie den QR-Code mit einer Authenticator-App (die Zwei-Faktor-Anmeldung ist Pflicht) und bewahren Sie die Wiederherstellungscodes auf.

Dateien und Dienste

PfadInhalt
/etc/watchzit/server.envDatenbankadresse und Update-Quelle.
/var/lib/watchzitZertifikate, der geheime Schlüssel (sichern Sie ihn zusammen mit der Datenbank), Downloads, Protokolle.
watchzit-server.serviceDer Server. journalctl -u watchzit-server zeigt sein Protokoll.
watchzit-helper.pathDer root-Helfer für Updates, Zeitzone und Neustarts aus der Konsole.

Sichern Sie die Datenbank und /var/lib/watchzit/secret.key: Gespeicherte Passwörter (SNMP, Datenbanken, Kanäle) sind damit verschlüsselt.
