Fehlerbehebung und FAQ

Ping meldet „ICMP is not allowed“

Der Server braucht das Recht, ICMP zu senden. Der paketierte Dienst hat es (CAP_NET_RAW). Andernorts erteilen Sie es mit setcap cap_net_raw+ep /usr/bin/watchzit-server oder erlauben unprivilegiertes Ping: sysctl net.ipv4.ping_group_range="0 2147483647".

SNMP zeigt „no answer“

  • Prüfen Sie im Profil die Community bzw. den SNMPv3-Benutzer, die Protokolle und die Passwörter.
  • Erlauben Sie auf dem Gerät die Adresse des WatchZit-Servers (viele Geräte antworten nur eingetragenen Managern) und auf Firewalls UDP 161.
  • Die Meldung sagt es, wenn ein v3-Benutzer unbekannt oder das Passwort falsch ist.

Ein Agent verbindet sich nicht

  • Der Computer muss den Agenten-Port 8444 des Servers erreichen; prüfen Sie Einstellungen → Netzwerk und Zugriff (erlaubte Netzwerke, öffentliche Agenten-Adresse).
  • Windows: Get-Service WatchZitAgent und das Protokoll in C:\ProgramData\WatchZit Agent. Linux: journalctl -u watchzit-agent.
  • „the server does not know this agent“: Das Gerät wurde entfernt; registrieren Sie es erneut mit einem neuen Code.

Benachrichtigungen kommen nicht an

  • Senden Sie einen Test aus Einstellungen → Benachrichtigungen; die Kanalliste zeigt den letzten Fehler.
  • Probleme in einer Wartung oder hinter einem ausgefallenen Gerät werden nicht gesendet; prüfen Sie den niedrigsten Schweregrad des Kanals.

Ich habe mich ausgesperrt

Nach zu vielen fehlgeschlagenen Anmeldungen wird die Adresse für eine Weile gesperrt. Auf dem Server: watchzit-server --unblock-ip all. Wenn die erlaubten Netzwerke Sie ausschließen: watchzit-server --reset-allowlist.

Wo sind die Protokolle?

journalctl -u watchzit-server und /var/lib/watchzit/logs/server.log; der Update-Helfer schreibt /var/log/watchzit-helper/helper.log. Einstellungen → Diagnose zeigt die neuesten Zeilen und liefert ein ZIP ohne Geheimnisse, das Sie an den Support senden können.

FAQ

Brauchen Geräte einen Agenten? Nein. Ping-, Port-, SNMP-, Web-, DNS-, Datenbank- und API-Prüfungen laufen vom Server aus; der Agent ergänzt, was nur der Computer selbst weiß.

Wie viele Geräte? Ein Server fragt Tausende Prüfungen pro Minute ab; Messwerte werden komprimiert, sodass auch ein Jahr an Daten klein bleibt.

Ist es kostenlos? Ja, unter der AGPL-3.0. MaxZit bietet kostenpflichtigen Support an.
