Datenquellen

Diagramme und Dashboards können auch Zeitreihen von außerhalb von WatchZit zeigen: Tabellen Ihrer eigenen Datenbanken, Prometheus, InfluxDB oder jede Adresse, die JSON liefert — neben den Werten von Agenten und Prüfungen.

Datenquelle hinzufügen

Administratoren fügen Datenquellen unter Einstellungen → Datenquellen hinzu:

ArtAdresseAnmeldung
PostgreSQLHost oder Host:Port (5432) und die DatenbankBenutzer und Passwort
MySQL / MariaDBHost oder Host:Port (3306) und die DatenbankBenutzer und Passwort
Microsoft SQL ServerHost oder Host:Port (1433) und die DatenbankSQL-Server-Benutzer und Passwort
Prometheusdie URL, zum Beispiel http://prometheus:9090; auch Thanos, VictoriaMetrics, Mimirkeine, Benutzer und Passwort oder ein Bearer-Token
InfluxDBdie URL, zum Beispiel http://influx:8086, und die Datenbank (InfluxDB 2/3: der Bucket)InfluxDB 1: Benutzer und Passwort; 2 und 3: nur das Token
JSON über HTTPdie Basis-URL Ihres Diensteskeine, Benutzer und Passwort oder ein Bearer-Token

Verbindung testen probiert die Einstellungen aus, ohne sie zu speichern. Passwort oder Token werden verschlüsselt gespeichert und nie wieder angezeigt; lassen Sie das Feld leer, um sie zu behalten.

Wählen Sie für SQL-Datenbanken die Verschlüsselung: wenn der Server sie anbietet (Standard), immer mit beliebigem Zertifikat, immer mit vertrauenswürdigem Zertifikat oder nie. Für Adressen mit https:// kann ein selbstsigniertes Zertifikat akzeptiert werden.

Geben Sie der Konsole einen Benutzer, der nur lesen darf — und zwar nur die Tabellen, die sie braucht. WatchZit führt PostgreSQL- und MySQL-Abfragen in einer Nur-Lese-Transaktion aus; SQL Server kennt so etwas nicht, dort schützen also nur die Rechte des Benutzers die Daten. Operatoren schreiben Abfragen; Betrachter sehen nur die Diagramme.

Abfragen in Diagrammen

Klicken Sie auf einer Geräteseite auf Diagramme bearbeiten, dann auf ✎ bei einem Diagramm oder auf Diagramm hinzufügen. Klicken Sie unter Datenquellen auf Abfrage hinzufügen, wählen Sie die Datenquelle und schreiben Sie die Abfrage. Ausprobieren führt sie über den Zeitbereich der Seite aus und nennt die Reihen, die sie liefert (mit ihrer Anzahl an Punkten), oder den Fehler der Datenbank. Ein Diagramm kann bis zu 6 Abfragen neben den Werten des Geräts zeigen, jede mit einem Reihennamen, einer Einheit und einer Farbe.

Fügen Sie auf Dashboards das Widget Diagramm aus einer Datenquelle hinzu.

Die Antworten werden 20 Sekunden lang zwischengespeichert, sodass ein Dashboard auf mehreren Bildschirmen die Datenbank nur einmal abfragt. Eine Abfrage liefert höchstens 200.000 Zeilen und 50 Reihen und darf 20 Sekunden dauern; die Werte werden auf die Breite des Diagramms ausgedünnt.

SQL (PostgreSQL, MySQL, SQL Server)

Die Abfrage liefert eine Zeitspalte (namens time oder die erste Spalte mit Zeitangaben; Unix-Sekunden oder -Millisekunden funktionieren auch), eine oder mehrere numerische Spalten (je eine Reihe) und optional eine Textspalte, die die Reihe benennt (metric oder die erste Textspalte), für Tabellen mit einer Zeile pro Reihe und Zeitpunkt. Sortieren Sie nach der Zeit.

Makros setzen den Zeitbereich des Diagramms in die Abfrage ein:

MakroWird zu
$__timeFilter(col)col zwischen Anfang und Ende des Bereichs
$__timeGroup(col)col abgerundet auf das Intervall des Diagramms; $__timeGroup(col, 300) auf 5 Minuten
$__timeFrom, $__timeToAnfang und Ende als Zeitpunkt
$__unixFrom, $__unixToAnfang und Ende in Unix-Sekunden
$__interval_sdas Intervall des Diagramms in Sekunden

Beispiele:

-- Bestellungen pro Intervall (PostgreSQL, MySQL, SQL Server gleichermaßen)
SELECT $__timeGroup(created_at) AS time, count(*) AS orders
FROM orders WHERE $__timeFilter(created_at)
GROUP BY 1 ORDER BY 1

-- eine Reihe pro Lager
SELECT $__timeGroup(ts) AS time, warehouse AS metric, avg(temp) AS value
FROM sensor_readings WHERE $__timeFilter(ts)
GROUP BY 1, 2 ORDER BY 1

Prometheus

Schreiben Sie PromQL, zum Beispiel rate(node_network_receive_bytes_total{device="eth0"}[5m]) * 8. Jede Reihe wird so benannt, wie Prometheus sie schreibt (name{label="value"}); ein Reihenname im Editor ersetzt ihn. Die Schrittweite richtet sich nach der Breite des Diagramms.

InfluxDB

Schreiben Sie InfluxQL mit $timeFilter und $__interval:

SELECT mean("usage_idle") FROM "cpu" WHERE $timeFilter GROUP BY time($__interval), "host"

InfluxDB 2 und 3 beantworten InfluxQL über ihre 1.x-API: Ordnen Sie den Bucket dort einer Datenbank zu, falls das noch nicht geschehen ist.

JSON über HTTP

Die Abfrage ist ein Pfad oder Parameter, die an die Adresse angehängt werden (zum Beispiel /api/temps?room=server); WatchZit fügt from, to und step in Unix-Sekunden hinzu und liest jede dieser Antworten (Zeiten in Sekunden oder Millisekunden):

[{"target": "temp", "datapoints": [[21.5, 1793268000000], ...]}, ...]
{"temp": [[1793268000, 21.5], ...], "humidity": [[1793268000, 40], ...]}
[[1793268000, 21.5], [1793268060, 21.7], ...]
