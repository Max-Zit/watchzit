Erste Schritte

WatchZit ist ein selbst gehostetes System zur Überwachung von Netzwerken und Geräten. Eine Live-Netzwerkkarte zeigt, was womit verbunden ist und wie es ihm geht; dahinter stehen Prüfungen, Diagramme, Alarme, Dashboards und Berichte — auf Ihrem eigenen Server, unter der Lizenz AGPL-3.0.

Was WatchZit leistet

BereichWas Sie bekommen
NetzwerkkartenZeichnen Sie Ihr Netzwerk mit echten Gerätebildern, Racks und Kabeln von Port zu Port; die Karte zeigt Zustand und Datenverkehr live. Netzwerkkarten
PrüfungenPing, TCP-Ports, Webseiten, TLS-Zertifikate, DNS, PostgreSQL und MySQL, SNMP (v1/v2c/v3: Schnittstellen, CPU, Arbeitsspeicher, Datenträger, beliebige OIDs), die MikroTik RouterOS API und Werte aus beliebigen JSON-APIs. Geräte und Prüfungen
AgentEin kleiner, optionaler Agent für Windows und Linux meldet CPU, Arbeitsspeicher, Datenträger, Schnittstellen und ausgewählte Dienste. Agenten
AlarmeTrigger öffnen Probleme; Abhängigkeiten, Wartungsfenster und Bestätigungen halten das Rauschen gering; Benachrichtigungen per E-Mail, Webhook, Slack und Teams. Probleme und Alarme
Diagramme, Dashboards, BerichteDiagramme jedes Werts von einer Stunde bis zu einem Jahr, Dashboards für einen Wandbildschirm, Verfügbarkeitsberichte. Dashboards und Berichte
Geräte öffnenÖffnen Sie die Webseite eines Geräts, SSH, Remotedesktop, WinBox oder Ihre eigenen Werkzeuge mit einem Klick. Geräte öffnen

So funktioniert es

  • Der Server läuft unter Linux mit PostgreSQL. Er hat zwei Ports: die Konsole (Weboberfläche und REST-API, TCP 8443) und den Agenten-Endpunkt (TCP 8444).
  • Der Server fragt die Geräte selbst ab (Ping, TCP, SNMP, HTTP, Datenbanken, APIs). Auf den Geräten muss dafür nichts installiert werden.
  • Agenten sind optional. Sie verbinden sich ausgehend mit dem Agenten-Port und melden sich jede Minute; die Computer brauchen keine offenen Ports.
  • Jede Änderung in der Konsole wird in das manipulationssichere Prüfprotokoll geschrieben.

Erste Schritte

  1. Installieren Sie den Server — siehe Server installieren.
  2. Legen Sie den ersten Administrator an — mit dem Einrichtungstoken, das das Installationsprogramm anzeigt — und richten Sie die Zwei-Faktor-Anmeldung mit einer Authenticator-App ein.
  3. Fügen Sie Geräte hinzu unter Geräte: Ein Name und eine Adresse genügen; Ping wird automatisch hinzugefügt. Fügen Sie ein SNMP-Profil hinzu, um Schnittstellen und Datenverkehr zu lesen.
  4. Zeichnen Sie eine Karte unter Karten und verbinden Sie die Geräte von Port zu Port.
  5. Richten Sie Benachrichtigungen ein unter Einstellungen → Benachrichtigungen; die eingebauten Trigger überwachen bereits ausgefallene Geräte, volle Datenträger und ablaufende Zertifikate.

Die Konsole ist standardmäßig nur aus privaten Netzwerken erreichbar. Belassen Sie es dabei und öffnen Sie nur den Agenten-Port (8444) dort, wo Agenten ihn brauchen.
