REST API

Skripty a jiné systémy přes JSON API čtou zařízení, kontroly, grafy a problémy, potvrzují problémy a plánují údržbu.

Tokeny

Token vytvořte v Můj účet → API tokeny: název a kolik dní platí. Zobrazí se jen jednou. Token jedná za vás, s vaší rolí (token pozorovatele může jen číst); když už ho nepotřebujete, odvolejte ho. Neplatné tokeny se počítají jako neúspěšná přihlášení a na čas adresu zablokují.

Posílejte ho v hlavičce; API nikdy nepřijímá cookie relace konzole:

curl -H "Authorization: Bearer wzat_…" https://monitor.example.com:8443/api/v1/status

POST /api/v1/problems/{id}/ackpotvrzení: {"note": "…"}

POST /api/v1/maintenancenaplánování okna: {"name", "starts_at", "ends_at", "device_ids", "group_ids"}

Časy jsou ve formátu RFC 3339 (2026-11-01T22:00:00+01:00). Chyby mají tvar {"error": "…"} s odpovídajícím stavem HTTP. Změny se zapisují do protokolu auditu s názvem tokenu.
