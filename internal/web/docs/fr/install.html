Installer le serveur

WatchZit fonctionne sur un serveur Linux 64 bits (une petite machine virtuelle suffit) avec PostgreSQL. Le script d'installation met tout en place ; des paquets et une image d'appliance prête à l'emploi sont également disponibles.

Prérequis

  • Debian 12+, Ubuntu 22.04+, AlmaLinux ou Rocky Linux 9+, x86-64.
  • 2 cœurs CPU et 2 Go de mémoire pour quelques centaines d'appareils ; 10 Go de disque (les mesures sont stockées de façon compacte : une heure de temps de ping occupe environ 100 octets).
  • Ports : 8443 pour la console (vos réseaux d'administration), 8444 pour les agents (uniquement là où se trouvent des agents).

Script d'installation

En tant que root sur le serveur :

curl -fsSL https://github.com/Max-Zit/watchzit/releases/latest/download/install.sh | sudo sh

Le script installe PostgreSQL, télécharge la dernière version, vérifie sa signature avec la clé de publication de WatchZit, installe le paquet, crée la base de données avec un mot de passe aléatoire, ouvre les ports dans firewalld ou ufw et démarre le service. À la fin, il affiche l'adresse de la console et le jeton de configuration.

Options : --version X (une version donnée), --db postgres://… (une base de données existante au lieu d'un PostgreSQL local), --no-auto-updates (ne pas activer les mises à jour de sécurité du système), --source URL (un miroir ou un dossier local contenant les fichiers de la version). Relancer le script met WatchZit à jour et conserve les données.

Paquets

Chaque version comprend un paquet .deb et un paquet .rpm du serveur. Ils installent le programme, les services systemd et les installateurs des agents ; définissez WATCHZIT_DB dans /etc/watchzit/server.env et démarrez watchzit-server.

Appliance

L'appliance est une image prête à l'emploi (Debian avec WatchZit, PostgreSQL et les mises à jour de sécurité automatiques). Importez-la dans VMware, Proxmox ou Hyper-V, démarrez-la et suivez le menu à l'écran : il affiche l'adresse de la console et le jeton de configuration, et configure le réseau.

Images : OVA (VMware ESXi, Workstation, VirtualBox), qcow2 (Proxmox, KVM), VHDX (Hyper-V génération 1) et un ISO qui installe l'appliance sur une nouvelle VM ou un serveur physique (il efface le premier disque). Attribuez-lui 2 CPU, 2 Go de mémoire et un disque de 16 Go ou plus ; un disque plus grand est utilisé automatiquement. Connectez-vous à l'écran en tant que wzadmin avec le mot de passe initial watchzit ; vous devez immédiatement en choisir un nouveau. Le menu configure le réseau (DHCP ou une adresse fixe), le nom du serveur, le fuseau horaire et SSH (activé ou non, port), et définit un nouveau mot de passe pour un utilisateur de la console comme admin (en levant tous les blocages de connexion). Le réseau, SSH, les mises à jour du système d'exploitation et un certificat de confiance peuvent aussi être réglés dans la console (voir Utilisateurs, paramètres et mises à jour). SSH n'autorise aucune connexion en root.

Première connexion

  1. Ouvrez https://<serveur>:8443. Le navigateur avertit une fois au sujet du certificat auto-signé ; acceptez-le.
  2. Saisissez le jeton de configuration et créez le premier administrateur.
  3. Scannez le code QR avec une application d'authentification (la connexion à deux facteurs est obligatoire) et conservez les codes de récupération.

Fichiers et services

CheminContenu
/etc/watchzit/server.envAdresse de la base de données et source des mises à jour.
/var/lib/watchzitCertificats, la clé secrète (sauvegardez-la avec la base de données), téléchargements, journaux.
watchzit-server.serviceLe serveur. journalctl -u watchzit-server affiche son journal.
watchzit-helper.pathL'assistant root pour les mises à jour, le fuseau horaire et les redémarrages depuis la console.

Sauvegardez la base de données et /var/lib/watchzit/secret.key : les mots de passe enregistrés (SNMP, bases de données, canaux) sont chiffrés avec cette clé.
