Premiers pas

WatchZit est un système de surveillance des réseaux et des appareils que vous hébergez vous-même. Une carte réseau en direct montre ce qui est relié à quoi et dans quel état ; derrière elle se trouvent des contrôles, des graphiques, des alertes, des tableaux de bord et des rapports — sur votre propre serveur, sous licence AGPL-3.0.

Fonctionnement

  • Le serveur fonctionne sous Linux avec PostgreSQL. Il possède deux ports : la console (interface web et API REST, TCP 8443) et le point d'accès des agents (TCP 8444).
  • Le serveur interroge lui-même les appareils (ping, TCP, SNMP, HTTP, bases de données, API). Rien n'a besoin d'être installé sur les appareils pour cela.
  • Les agents sont facultatifs. Ils se connectent en sortie au port des agents et envoient leurs données chaque minute ; les ordinateurs n'ont besoin d'aucun port ouvert.
  • Chaque modification faite dans la console est inscrite dans le journal d’audit infalsifiable.

Premières étapes

  1. Installez le serveur — voir Installer le serveur.
  2. Créez le premier administrateur avec le jeton de configuration affiché par l'installateur, puis configurez la connexion à deux facteurs avec une application d'authentification.
  3. Ajoutez des appareils dans Appareils : un nom et une adresse suffisent ; le ping est ajouté pour vous. Ajoutez un profil SNMP pour lire les interfaces et le trafic.
  4. Dessinez une carte dans Cartes et reliez les appareils de port à port.
  5. Configurez les notifications dans Paramètres → Notifications ; les déclencheurs intégrés surveillent déjà les appareils en panne, les disques pleins et les certificats qui expirent.

Par défaut, la console n'est accessible que depuis des réseaux privés. Gardez ce réglage et n'ouvrez que le port des agents (8444), là où les agents en ont besoin.
