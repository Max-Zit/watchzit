Dépannage et FAQ

Le ping indique « ICMP is not allowed »

Le serveur a besoin du droit d'envoyer de l'ICMP. Le service fourni par les paquets le possède (CAP_NET_RAW). Ailleurs, accordez-le avec setcap cap_net_raw+ep /usr/bin/watchzit-server ou autorisez le ping non privilégié : sysctl net.ipv4.ping_group_range="0 2147483647".

SNMP affiche « no answer »

  • Vérifiez dans le profil la communauté ou l'utilisateur SNMPv3, les protocoles et les mots de passe.
  • Autorisez l'adresse du serveur WatchZit sur l'appareil (de nombreux appareils ne répondent qu'aux gestionnaires listés) et UDP 161 sur les pare-feux.
  • Le message le précise lorsqu'un utilisateur v3 est inconnu ou que le mot de passe est erroné.

Un agent ne se connecte pas

  • L'ordinateur doit atteindre le port des agents 8444 du serveur ; vérifiez Paramètres → Réseau et accès (réseaux autorisés, adresse publique des agents).
  • Windows : Get-Service WatchZitAgent et le journal dans C:\ProgramData\WatchZit Agent. Linux : journalctl -u watchzit-agent.
  • « the server does not know this agent » : l'appareil a été supprimé ; inscrivez-le de nouveau avec un nouveau code.

Les notifications n'arrivent pas

  • Envoyez un test depuis Paramètres → Notifications ; la liste des canaux affiche la dernière erreur.
  • Les problèmes en maintenance ou situés derrière un appareil en panne ne sont pas envoyés ; vérifiez la gravité minimale du canal.

Je me suis bloqué l'accès

Après trop de connexions échouées, l'adresse est bloquée pendant un moment. Sur le serveur : watchzit-server --unblock-ip all. Si les réseaux autorisés vous excluent : watchzit-server --reset-allowlist.

Où se trouvent les journaux ?

journalctl -u watchzit-server et /var/lib/watchzit/logs/server.log ; l'assistant de mise à jour écrit dans /var/log/watchzit-helper/helper.log. Paramètres → Diagnostic affiche les dernières lignes et fournit un ZIP sans secrets à envoyer au support.

FAQ

Les appareils ont-ils besoin d'un agent ? Non. Les contrôles ping, de ports, SNMP, web, DNS, de bases de données et d'API s'exécutent depuis le serveur ; l'agent ajoute ce que seul l'ordinateur lui-même connaît.

Combien d'appareils ? Un serveur exécute des milliers de contrôles par minute ; les mesures sont compressées, si bien qu'une année de données reste peu volumineuse.
