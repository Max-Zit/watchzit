Opening devices

From a device page or the map's side panel you open a device with the right program: its web interface, SSH, Remote Desktop, WinBox, VNC or your own tools.

The MaxZit Launcher

A browser cannot start programs, so a small Windows program does it: the MaxZit Launcher. Install it once per computer from the Launcher page — it installs for your Windows user, without administrator rights — and click Pair this computer. The launcher shows the server's fingerprint; it must match the one on the page.

Then the Open with buttons work. The first time, the browser asks whether it may open the launcher; allow it.

The same launcher serves PassZit: in the PassZit extension's menu click Pair with the MaxZit Launcher and agree in the launcher's own window. PassZit then opens Remote Desktop, SSH, WinSCP, WinBox, VNC and Telnet with the login from the vault — Remote Desktop through a Windows credential that exists only for a few seconds, an SSH password or key through a file only you can read that is removed right after the start. The launcher replaces the older WatchZit Launcher and passzit-helper: installing it takes over their settings and pairings. When PassZit is paired and the console's address is one of its trusted MaxZit consoles, the Open with buttons of WatchZit open signed in with the matching login from the vault; without PassZit, or without a login for that device, they open as before. The console only tells PassZit the tool, address, port, user name and device name — never a password.

How it stays safe

  • Every click gives a link signed by your server that is valid for a minute and works once; the launcher accepts links only from servers you paired.
  • Addresses and user names are checked against strict character sets; programs start with an argument list, never through a shell.
  • Passwords are never stored or sent: the program asks for them.
  • Before a program added by your administrator runs for the first time, the launcher asks you.

Programs in other places: write their paths into %APPDATA%\MaxZit Launcher\launcher.json. Without the launcher, Remote Desktop still works: the .rdp button downloads a file Windows opens.

Your own tools

Under Settings → Tools administrators switch built-in tools off, limit them to device types and add their own: a program path (for example %ProgramFiles%\Mozilla Firefox\firefox.exe) and arguments with {host}, {port}, {user} and {name}. The user name and ports per device are set in the device's Remote access.

Links on every device

Also under Settings → Tools, Links on every device adds buttons to every device page that open the device in another program in the browser, for example RMMZit or BackupZit. Give a name and an address; {name}, {address} and {id} are replaced by the device's name, address and number, e.g. https://rmm.example.com:8443/devices?q={name}. Only http:// and https:// addresses are accepted.
