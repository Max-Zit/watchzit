Opening devices

From a device page or the map's side panel you open a device with the right program: its web interface, SSH, Remote Desktop, WinBox, VNC or your own tools.

The WatchZit Launcher

A browser cannot start programs, so a small Windows program does it: the WatchZit Launcher. Install it once per computer from the Launcher page — it installs for your Windows user, without administrator rights — and click Pair this computer. The launcher shows the server's fingerprint; it must match the one on the page.

Then the Open with buttons work. The first time, the browser asks whether it may open the launcher; allow it.

How it stays safe

  • Every click gives a link signed by your server that is valid for a minute and works once; the launcher accepts links only from servers you paired.
  • Addresses and user names are checked against strict character sets; programs start with an argument list, never through a shell.
  • Passwords are never stored or sent: the program asks for them.
  • Before a program added by your administrator runs for the first time, the launcher asks you.

TelnetPuTTY

Programs in other places: write their paths into %APPDATA%\WatchZit Launcher\launcher.json. Without the launcher, Remote Desktop still works: the .rdp button downloads a file Windows opens.

Your own tools

Under Settings → Tools administrators switch built-in tools off, limit them to device types and add their own: a program path (for example %ProgramFiles%\Mozilla Firefox\firefox.exe) and arguments with {host}, {port}, {user} and {name}. The user name and ports per device are set in the device's Remote access.
