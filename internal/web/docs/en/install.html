Installing the server

WatchZit runs on a 64-bit Linux server (a small virtual machine is enough) with PostgreSQL. The install script sets up everything; packages and a ready-made appliance image are available too.

Requirements

  • Debian 12+, Ubuntu 22.04+, AlmaLinux or Rocky Linux 9+, x86-64.
  • 2 CPU cores and 2 GB of memory for a few hundred devices; 10 GB of disk (measurements are stored compactly: an hour of ping times takes about 100 bytes).
  • Ports: 8443 for the console (your admin networks), 8444 for agents (only where agents are).

Install script

As root on the server:

curl -fsSL https://github.com/Max-Zit/watchzit/releases/latest/download/install.sh | sudo sh

The script installs PostgreSQL, downloads the newest release, checks its signature with the WatchZit release key, installs the package, creates the database with a random password, opens the ports in firewalld or ufw and starts the service. At the end it prints the console address and the setup token.

Options: --version X (a given release), --db postgres://… (an existing database instead of a local PostgreSQL), --no-auto-updates (do not switch on the OS security updates), --source URL (a mirror or a local folder with the release files). Running the script again updates WatchZit and keeps the data.

Packages

Each release has a .deb and an .rpm of the server. They install the program, the systemd services and the agent installers; set WATCHZIT_DB in /etc/watchzit/server.env and start watchzit-server.

Appliance

The appliance is a ready-made image (Debian with WatchZit, PostgreSQL and automatic security updates). Import it into VMware, Proxmox or Hyper-V, start it and follow the menu on its screen: it shows the console address and the setup token, and sets the network.

First sign-in

  1. Open https://<server>:8443. The browser warns once about the self-signed certificate; accept it.
  2. Enter the setup token and create the first administrator.
  3. Scan the QR code with an authenticator app (two-factor sign-in is required) and keep the recovery codes.

Files and services

PathWhat
/etc/watchzit/server.envDatabase address and update source.
/var/lib/watchzitCertificates, the secret key (back it up with the database), downloads, logs.
watchzit-server.serviceThe server. journalctl -u watchzit-server shows its log.
watchzit-helper.pathThe root helper for updates, time zone and restarts from the console.

Back up the database and /var/lib/watchzit/secret.key: stored passwords (SNMP, databases, channels) are encrypted with it.
