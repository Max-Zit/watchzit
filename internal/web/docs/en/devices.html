Devices, checks and SNMP

A device is anything with an address: a router, switch, server, printer, camera or a web site. Checks measure it; their results colour the device, the map and the graphs.

Adding a device

Under Devices → Add a device enter a name and an IP address or host name, choose its type and group, and leave Ping on. Optional:

  • SNMP — a profile with the community or the SNMPv3 user; WatchZit then reads the interfaces, traffic, CPU, memory and disks.
  • Depends on — the router or switch the device is reached through. While it is down, this device's problems are only "unreachable" and are not sent.
  • Remote access — the user name and ports that tools use.
  • TCP ports — each becomes a check that connects every minute.

The device's state comes from its checks: up when all are up, partly down when some are down, down when all are.

Check types

CheckMeasures
Ping (ICMP)Response time and packet loss.
TCP portWhether the port accepts connections, and how fast.
Web page (HTTP)Status code, response time, a text that must be on the page, days until the certificate expires.
TLS certificateDays until it expires and whether it is trusted (any TLS port, with a server name for SNI).
DNSThe device is a DNS server: it must answer a name with a record type (A, AAAA, MX …) and, optionally, an expected value.
PostgreSQL, MySQL / MariaDBSign-in with a monitoring user, version, number of connections, response time.
MikroTik RouterOS (API)CPU, memory, uptime and temperature over the REST API of RouterOS 7.
JSON API valueOne number from any JSON API (FortiGate, vCenter, your own services): an address, a path like results.cpu.0.current, and optional Bearer or basic sign-in.
SNMPAvailability and uptime; interfaces, CPU and storage found by discovery; any numeric OID.

Passwords and tokens of checks are stored encrypted and never shown again; leave the field empty when you edit a check to keep the stored one.

SNMP

  1. Create a profile under Settings → SNMP: v2c with a community, or v3 with a user (SHA-2 and AES are supported).
  2. Choose the profile on the device. WatchZit opens SNMP discovery: tick the interfaces, CPU, memory and disks to watch (loopbacks and interfaces without link are left out).
  3. The device page then shows ports with link state and live traffic, and graphs of every value.

MikroTik, Cisco, HP, Ubiquiti, printers and UPS devices speak SNMP. On Linux install snmpd; on Windows the SNMP service.

Graphs

Every value is kept: raw for days, then as 5-minute and hourly minimum, average and maximum (Settings → Metric data). On a graph drag to zoom in, double-click to go back; the time range buttons go from one hour to a year.
