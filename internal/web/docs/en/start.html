Getting started

WatchZit is a self-hosted network and device monitoring system. A live network map shows what is connected to what and how it is doing; behind it are checks, graphs, alerts, dashboards and reports — on your own server, under the AGPL-3.0 licence.

What WatchZit does

How it works

  • The server runs on Linux with PostgreSQL. It has two ports: the console (web interface and REST API, TCP 8443) and the agent endpoint (TCP 8444).
  • The server polls devices itself (ping, TCP, SNMP, HTTP, databases, APIs). Devices need nothing installed for that.
  • Agents are optional. They connect outbound to the agent port and report every minute; the computers need no open ports.
  • Every change in the console is written to the tamper-evident audit log.

First steps

  1. Install the server — see Installing the server.
  2. Create the first administrator with the setup token shown by the installer, and set up two-factor sign-in with an authenticator app.
  3. Add devices under Devices: a name and an address are enough; ping is added for you. Add an SNMP profile to read interfaces and traffic.
  4. Draw a map under Maps and connect the devices port to port.
  5. Set up notifications under Settings → Notifications; the built-in triggers already watch for devices that are down, full disks and expiring certificates.

The console is reachable only from private networks by default. Keep it that way and open only the agent port (8444) where agents need it.
