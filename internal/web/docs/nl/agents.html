Agents installeren

De WatchZit-agent is optioneel. Hij rapporteert wat het netwerk van buitenaf niet kan zien: CPU, geheugen, schijven, interfaces en services van Windows- en Linux-computers, elke minuut, via één uitgaande verbinding.

Aanmeldcodes

Maak onder Agents een aanmeldcode aan: een naam, hoeveel dagen hij geldig is, hoeveel computers hem mogen gebruiken en de groep waarin nieuwe apparaten komen. De code wordt één keer getoond; hij bevat het serveradres en de vingerafdruk van het agentcertificaat, zodat de agent alleen uw server vertrouwt.

Windows

Download de MSI van de pagina Agents en installeer hem; hij vraagt om de code. Installeer hem voor veel computers stil (GPO, Intune, een script):

msiexec /i watchzit-agent-x64.msi ENROLLCODE="WZ1-…" /qn

De agent draait als de service WatchZitAgent.

Linux

De pagina Agents toont een opdracht die de agent via de agentpoort downloadt, de SHA-256 ervan controleert en hem met de code installeert (systemd-service watchzit-agent):

curl -fsSk https://<server>:8444/agent/download/watchzit-agent-linux-amd64 -o /tmp/watchzit-agent && … sudo /tmp/watchzit-agent install --code "WZ1-…"

Of installeer het deb- of rpm-pakket van de release (amd64 en arm64, van GitHub), en meld de agent daarna aan en start hem; updates komen via de pakketbeheerder of via de eigen updates van de agent:

sudo apt install ./watchzit-agent_<versie>_amd64.deb      # of: sudo dnf install ./watchzit-agent-<versie>-1.x86_64.rpm
sudo watchzit-agent enroll --code "WZ1-…"
sudo systemctl start watchzit-agent

Wat de agent rapporteert

  • CPU-belasting (en load average op Linux), geheugen en swap, elke schijf, elke netwerkinterface met verkeer — ze worden vanzelf controles met grafieken.
  • Inventaris: besturingssysteem, CPU-model, geheugen, fabrikant, model, serienummer, adressen, services.
  • Hyper-V-machines (Windows) en Docker-containers (Linux), elke vijf minuten, met hun status, CPU, geheugen en adressen; ze verschijnen op de apparaatpagina en in hypervisorvakken op kaarten.
  • Bewaakte services: kies ze op de apparaatpagina onder Services bewaken; een service die stopt opent een probleem.
  • Bewaakte processen: voer onder Processen bewaken op de apparaatpagina programmanamen in (bijvoorbeeld nginx, sqlservr.exe, java); elk krijgt een controle met hoeveel er draaien, hun CPU en geheugen, en als er geen draait wordt een probleem geopend.
  • Foutmeldingen van het systeem — kritieke en foutgebeurtenissen uit de Windows-logboeken System en Application, en berichten met prioriteit err en erger uit het systemd-journal — gaan bij elk rapport naar Logboeken (soort Agents); een logtrigger met de bron Agents opent daaruit problemen.

Als er een apparaat met hetzelfde adres of dezelfde naam bestaat, sluit de agent zich daarbij aan; anders wordt een nieuw apparaat aangemaakt.

Agent-updates

Een agent die ouder is dan de server krijgt bij het verbinden (hoogstens één keer per uur) de agent van de serverversie: hij downloadt het installatieprogramma van de server via zijn eigen versleutelde, vastgepinde verbinding, controleert de grootte en de SHA-256 en installeert het. Windows-agents die met de MSI zijn geïnstalleerd voeren de nieuwe MSI uit; Linux-agents (systemd) controleren of het nieuwe programma start, vervangen zichzelf en worden door systemd herstart. De pagina Agents markeert oudere agents; beheerders schakelen daar onder Agent-updates de automatische updates uit en werken alle online agents met één klik bij. Agents van vóór 1.2 kennen nog geen updates en worden één keer met de hand bijgewerkt.

Externe collectors

Een apparaat in een ander netwerk — een filiaal, een klantlocatie achter NAT, een afgesloten beheer-VLAN — is vaak niet bereikbaar vanaf de console. Installeer de agent op een willekeurige computer daar (Linux of Windows; een kleine VM of een machine van het formaat Raspberry Pi is genoeg) en klik in het deel Agent van de apparaatpagina op Gebruiken als externe collector. Kies hem daarna onder Bewaakt vanaf bij de apparaten van dat netwerk (of voor veel tegelijk in de apparatenlijst onder Selectie wijzigen). De collector krijgt hun controles — ping, TCP, SNMP, webpagina's en scenario's, certificaten, DNS, databases, RouterOS, JSON-API's — met de wachtwoorden en SNMP-instellingen die ze nodig hebben, voert ze uit volgens hun intervallen en stuurt de resultaten via zijn eigen versleutelde verbinding. Hij heeft geen open poort op de locatie nodig en heeft geen eigen webinterface; alles wordt in de console ingesteld.

Zolang de verbinding met de console weg is, blijft de collector de controles uitvoeren; de resultaten (tot een dag, de nieuwste 200.000) wachten op de collector en komen binnen zodra de verbinding terug is, zodat de grafieken geen gat hebben. De controles van zijn apparaten tonen intussen onbekend in plaats van uitgevallen (de locatie kan in orde zijn), en de agentcontrole van de collector opent een probleem. Bewaarde resultaten overleven een herstart van de collector niet: hij krijgt zijn controles dan opnieuw van de console.

Reservecollector: installeer de agent op een tweede computer op de locatie, maak er ook een collector van en kies hem als Reserve naast Bewaakt vanaf (of voor veel apparaten in de apparatenlijst onder Selectie wijzigen → Reservecollector). Zolang de eerste offline is, voert de reserve hun controles uit; wanneer de eerste terug is, neemt die ze weer over.

Detectie en SNMP: kies onder Apparaten → Detectie de collector naast een nieuw bereik: hij scant dat netwerk van zijn locatie, en de apparaten die u eruit toevoegt worden vanaf hem bewaakt. De SNMP-detectie op de apparaatpagina en het uitlezen van gegevens, interfaces en VLAN's lopen ook via de collector. Hypervisorcontroles blijven bij de console. Stoppen met verzamelen geeft de apparaten terug aan de console.

Netwerk

Agents verbinden met agentpoort 8444. Stel onder Instellingen → Netwerk en toegang het openbaar agentadres in wanneer agents de server via een andere naam bereiken (bijvoorbeeld via een firewall), en beperk de netwerken waar agents vandaan mogen komen.

Als u de agent op de apparaatpagina verwijdert, wordt zijn sleutel onbekend; om de agent weer te gebruiken, meldt u de computer aan met een nieuwe code.
