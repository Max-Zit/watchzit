故障排除与常见问题

Ping 显示“ICMP is not allowed”

服务器需要发送 ICMP 的权限。软件包安装的服务已具备该权限（CAP_NET_RAW）。在其他环境中，可使用 setcap cap_net_raw+ep /usr/bin/watchzit-server 授予权限，或允许非特权 Ping：sysctl net.ipv4.ping_group_range="0 2147483647"。

SNMP 显示“无应答”

  • 检查配置文件中的团体名，或 SNMPv3 用户、协议和密码。
  • 在设备上允许 WatchZit 服务器的地址（许多设备只应答列表中的管理站），并在防火墙上放行 UDP 161。
  • 当 v3 用户未知或密码错误时，消息中会注明。

代理无法连接

  • 计算机必须能访问服务器的代理端口 8444；请检查设置 → 网络与访问（允许的网络、代理公共地址）。
  • Windows：Get-Service WatchZitAgent 以及 C:\ProgramData\WatchZit Agent 中的日志。Linux：journalctl -u watchzit-agent。
  • “the server does not know this agent”：该设备已被删除；请使用新的注册码重新注册。

收不到通知

  • 从设置 → 通知发送测试；渠道列表会显示最后一次错误。
  • 处于维护期间或位于宕机设备之后的问题不会发送；请检查渠道的最低严重程度。

我把自己锁在外面了

登录失败次数过多后，该地址会被暂时封锁。在服务器上运行：watchzit-server --unblock-ip all。如果允许的网络把您排除在外：watchzit-server --reset-allowlist。

日志在哪里？

journalctl -u watchzit-server 和 /var/lib/watchzit/logs/server.log；更新助手写入 /var/log/watchzit-helper/helper.log。设置 → 诊断会显示最新的日志行，并提供一个不含机密信息的 ZIP，可发送给技术支持。

常见问题

设备需要安装代理吗？不需要。Ping、端口、SNMP、Web、DNS、数据库和 API 检查都从服务器运行；代理补充只有计算机自身才知道的信息。

能监控多少台设备？一台服务器每分钟可轮询数千项检查；测量数据经过压缩，因此一年的数据也很小。

它是免费的吗？是的，采用 AGPL-3.0 许可证。MaxZit 提供付费支持。
