REST API

脚本和其他系统可以通过 JSON API 读取设备、检查、图表和问题，确认问题并计划维护。

令牌

在我的帐户 → API 令牌中创建令牌：指定名称和有效天数。令牌只显示一次。令牌以您的身份和角色执行操作（查看者的令牌只能读取）；不再需要时请将其吊销。验证失败的令牌与登录失败一样计数，并会暂时封锁该地址。

请在请求头中发送令牌；API 从不接受控制台的会话 Cookie：

curl -H "Authorization: Bearer wzat_…" https://monitor.example.com:8443/api/v1/status

端点

请求响应
GET /api/v1/status版本、按状态统计的设备、按严重程度统计的未解决问题
GET /api/v1/devices设备；筛选参数 q、status、group
GET /api/v1/devices/{id}一台设备及其检查，以及这些检查的序列 ID
GET /api/v1/series/{id}?range=24h序列的数据点：时间、最小值、平均值、最大值
GET /api/v1/problems未解决的问题；view=history、severity、device
POST /api/v1/problems/{id}/ack确认：{"note": "…"}
GET /api/v1/maintenance维护窗口
POST /api/v1/maintenance计划一个维护窗口：{"name", "starts_at", "ends_at", "device_ids", "group_ids"}

时间采用 RFC 3339 格式（2026-11-01T22:00:00+01:00）。错误以 {"error": "…"} 返回，并带有相应的 HTTP 状态码。更改会连同令牌名称一起写入审计日志。
