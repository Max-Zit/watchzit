快速入门

WatchZit 是一款自托管的网络与设备监控系统。实时网络地图展示哪些设备彼此相连以及它们的运行状况；其背后是检查、图表、告警、仪表板和报告——全部运行在您自己的服务器上，采用 AGPL-3.0 许可证。

WatchZit 能做什么

领域功能
网络地图使用真实的设备图片、机柜和端口到端口的线缆绘制网络；地图显示实时状态和流量。网络地图
检查Ping、TCP 端口、网页、TLS 证书、DNS、PostgreSQL 和 MySQL、SNMP（v1/v2c/v3：接口、CPU、内存、磁盘、任意 OID）、MikroTik RouterOS API，以及任意 JSON API 中的数值。设备与检查
代理适用于 Windows 和 Linux 的小型可选代理，上报 CPU、内存、磁盘、接口和所选服务。代理
告警触发器产生问题；依赖、维护窗口和确认机制减少干扰；可通过电子邮件、Webhook、Slack 和 Teams 发送通知。问题与告警
图表、仪表板、报告每个数值的图表，时间范围从一小时到一年；适合墙面大屏的仪表板；可用性报告。仪表板与报告
打开设备一键打开设备的网页、SSH、远程桌面、WinBox 或您自己的工具。打开设备

工作原理

  • 服务器运行在 Linux 上，使用 PostgreSQL。它有两个端口：控制台（Web 界面和 REST API，TCP 8443）和代理接入点（TCP 8444）。
  • 服务器自行轮询设备（Ping、TCP、SNMP、HTTP、数据库、API）。设备无需为此安装任何软件。
  • 代理是可选的。代理以出站方式连接到代理端口，每分钟上报一次；计算机无需开放任何端口。
  • 控制台中的每项更改都会写入防篡改的审计日志。

第一步

  1. 安装服务器——请参阅安装服务器。
  2. 使用安装程序显示的设置令牌创建第一个管理员，并使用身份验证器应用设置双因素登录。
  3. 在设备中添加设备：只需名称和地址即可，系统会自动添加 Ping。添加 SNMP 配置文件即可读取接口和流量。
  4. 在地图中绘制地图，并按端口连接设备。
  5. 在设置 → 通知中设置通知；内置触发器已经在监视宕机的设备、已满的磁盘和即将过期的证书。

默认情况下，控制台只能从私有网络访问。请保持此设置，只在代理需要的地方开放代理端口（8444）。
