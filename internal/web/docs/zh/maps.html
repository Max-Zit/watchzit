网络地图

地图既是网络的示意图，也是实时监控：设备按状态着色，线缆显示流量，端口可以放大查看。

绘制地图

  1. 在地图中添加地图并点击编辑。
  2. 添加设备将设备放到地图上；拖动它们到合适的位置。添加物品用于添加不受监控的东西（配线架、PDU）。编辑时，在物品面板中选择监控的设备可将其变为控制台中的设备：图片、位置、机架单元和线缆保持不变，并显示该设备的状态和指标。无（仅图片）可将设备变回物品。
  3. 连接：点击两台设备并选择两端的端口（来自 SNMP 或代理接口）。线缆会显示该端口的流量。
  4. 建议的链路会显示设备的连接位置（请参阅在设备上发现的链路），并提供带端口的线缆，以及与地图相连但尚未在地图上的设备；全部添加会将它们全部添加。
  5. 点击保存（或按 Ctrl+S）。更改在保存之前只保留在页面中；取消会返回已保存的地图。

图片、机柜和线缆

  • 每台设备都有一张来自内置图库的图片（带端口的交换机、路由器、服务器、防火墙、无线接入点、电话、摄像头 …），也可以使用您上传的图片。
  • 图库中还包含 180 多家制造商的约 3,500 个真实型号：服务器（G6 起的 HPE ProLiant、Dell PowerEdge、Lenovo、Supermicro、Cisco UCS、Fujitsu、Huawei/xFusion、Inspur）、NAS（Synology、QNAP、Asustor、TrueNAS 等）、SAN 存储和 FC 交换机（HPE MSA/3PAR/Nimble/Alletra、IBM Storwize/FlashSystem、Dell PowerVault/Unity/PowerStore、NetApp、Pure Storage、Lenovo、Fujitsu ETERNUS、Huawei OceanStor、Hitachi、Brocade、Cisco MDS）、交换机（Cisco、HPE Aruba、Dell、Juniper、Ubiquiti、Netgear、TP-Link、D-Link、Zyxel、Huawei、Arista、Extreme、Ruckus、Alcatel-Lucent、Ruijie、FS（fs.com：园区、PoE、数据中心和工业交换机、Wi-Fi、媒体转换器、光纤配线箱）、QNAP、TRENDnet、Hikvision、Dahua、Lancom、DrayTek、工业级 Moxa、Siemens SCALANCE、Hirschmann 和 Phoenix Contact 等）、防火墙（Fortinet、Palo Alto、Sophos、WatchGuard、SonicWall、Check Point、Cisco ASA/Firepower、Netgate 等）、MikroTik、家用和办公路由器及 Mesh Wi-Fi（TP-Link、ASUS、FRITZ!Box、Netgear、Linksys、D-Link、Huawei 和 ZTE 的 ONT 等）、无线接入点、UPS（塔式和机架式）、录像机和 IP 摄像头、室外点对点、扇区和全向天线、打印机、IP 电话和 PBX、刀片机箱、PDU、KVM 和控制台服务器、环境监测器和迷你 PC、GPON OLT 和 ONT、运营商路由器、SD-WAN 边缘设备、NTP 时间服务器、对讲机、视频会议设备、PLC 和 HMI。通用图片中还有机柜配件：理线器、毛刷面板、托盘、风扇托架、抽屉和盲板。通用图片中还有光纤配线架（LC 双工单模和多模、SC/APC 和 SC/UPC，12 到 96 口）和壁挂光纤盒。在图片面板中选择制造商（或所有制造商）和类型（交换机、路由器、防火墙、服务器、存储 / NAS、无线接入点 …），或搜索型号（例如“DL380 Gen10”或“CRS326”）；使用通用图片按类型或搜索时会查找所有制造商；图中包含该型号的端口和硬盘槽位，因此线缆会连接到正确的端口。对于设备，面板会以其制造商打开；将设备添加到地图时，如果其 SNMP 描述指明了图库中的某个型号（例如 MikroTik），会自动选择该图片。
  • 4 到 48 个单元的机柜：将设备拖入其中，它们会自动吸附到空闲单元。非机架式的设备——NAS、小型交换机、放在托盘上的迷你 PC——可以在设备面板中设置自己的高度（1–20U，否则使用图片的高度）和宽度（全宽、1/2、1/3 或 1/4），以及从左到右的位置，这样多台设备可以并排放在相同的单元中；拖入机柜时会占用最近的空闲位置。
  • 线缆有类别（铜缆、光纤、DAC、无线、VPN、WAN、串口、电源）和走线：直线、90° 或 45° 折线、曲线；拖动节点可弯曲线缆；双击节点可删除。
  • 背景图片（楼层平面图、站点图），可设置大小、透明度和位置。
  • 子地图链接到其他地图，并显示其中最差的状态。

查看地图

  • 绿色表示正常，橙色表示部分异常，红色表示故障（闪烁）；灰色表示未知或已暂停。
  • 线缆会随利用率变粗并改变颜色（超过 50 % 为橙色，超过 80 % 为红色）；端口没有链路的线缆显示为红色虚线。
  • 使用滚轮或双指缩放；距离足够近时会显示名称和端口标签。点击设备可打开其面板，其中包含检查、端口和工具——操作员和管理员还可以在那里使用编辑设备，保存后会返回地图；双击可打开设备。
  • 点击线缆可打开其面板：当前双向流量，以及最近一小时、一天、一周或一个月的流量历史（来自任一端的接口检查）。

HA 组

  • 互为备份的设备——防火墙 HA 对、VRRP 或 HSRP 路由器、交换机堆叠或 MLAG/vPC 对、服务器或存储集群——组成一个 HA 组：编辑时，在第一台设备的面板中选择 HA 组 → 新建 HA 组，然后在其他设备的面板中选择同一个组。组显示为包围其成员的虚线框；安装在机柜中的成员只有细轮廓线，并在相邻成员交界处显示一个小的 ⇅ HA 标签，这样周围的单元仍然清晰可见（点击标签可打开该组）；每个成员的标签旁会以小字显示 VRRP 角色——ACTIVE 为绿色，STANDBY 为橙色。组面板用于设置名称和类别。
  • 路径会经过组的每个成员，并显示所有等价路由（例如经过两台防火墙的 2 条路由）。请将成员之间的线缆（心跳、同步、堆叠、对等链路）设置为线缆类别 HA 链路；它不作为流量路径。
  • 所有成员正常时框（或标签）为绿色，部分成员故障时为橙色并显示冗余已失去，全部故障时为红色。此时触发器失去冗余的 HA 组会产生问题（请参阅“告警”）。
  • 上报 VRRP 的成员会显示 ACTIVE 或 STANDBY，组面板会显示其起始时间。

虚拟化主机与虚拟机

  • 添加虚拟化主机（编辑时）为虚拟化主机添加一个框：选择虚拟化平台（VMware ESXi、Proxmox VE、Hyper-V、XCP-ng、KVM、Nutanix AHV、Docker、Kubernetes 等）以及它所运行的物理服务器（必填；对于集群，在集群下添加其他服务器，路径可以经过其中任意一台）；服务器的状态显示在框上，可从面板打开其指标，并且当服务器在地图上时，会用虚线将两者相连。路径从虚拟机出发，经过其虚拟化主机和物理服务器，再沿线缆继续。
  • 将虚拟机拖入框中：可以是控制台中的设备（以查看其状态），也可以是带有其系统图片的物品（Windows Server、Ubuntu、Debian、Red Hat、MikroTik CHR、pfSense、容器等，在图片面板中选择类型虚拟机）。在框内它们会排列成网格；在框内拖动可改变顺序，拖出框外则从主机上移除。设备面板中也有运行在虚拟化主机上选项。
  • 自动显示虚拟化平台的虚拟机（新框默认开启）会用虚拟化平台检查、代理（Hyper-V、Docker）或 vCenter 为其物理服务器上报的虚拟机填充该框：运行中的为绿色，已停止的为灰色，已挂起的为黄色。地址或名称与控制台设备相符的虚拟机会显示为该设备。在您移动或连接其中一台，或按下放到地图上之前，这些虚拟机不属于已保存的地图；将虚拟机放到地图上会放置全部虚拟机。您自己放置的、使用虚拟机名称的物品也会获得其状态。
  • 框会显示其虚拟机和物理服务器中最差的状态；图层虚拟化主机可隐藏这些框。

图片库

菜单中的图片库用于保存您自己的设备图片。上传图片（PNG、JPEG、GIF、WebP 或 SVG；正面视图效果最佳），或使用内置图片：铅笔会修改内置图片本身，作用于所有使用它的地图（仅打开不会改变任何内容；只有保存更改时才会存储修改后的版本）（删除修改后的图片即可恢复为内置图片），复制则基于它创建一张您自己的新图片，用于相似的型号。在编辑器中设置：

  • 端口：点击图片添加端口，从端口 1 开始；拖动端口可移动，双击可删除。如需添加一排端口，输入端口数量，然后点击第一个和最后一个端口；两行会像交换机一样编号，1 在 2 上方。最后的 SFP 端口显示为橙色，并建议使用光纤线缆。
  • 机架单元 (U)（设备不上架时为 0）、制造商、类型以及在地图上的宽度。
  • 复制可基于您的某张图片创建新图片，用于相似的型号。

这些图片会按制造商和类型显示在地图的图片面板中，地图上的线缆会连接到您标记的端口。

图层和路径

  • 图层用于选择地图显示的内容：设备、机柜、物品、子地图、线缆、端口名称、流量、VLAN 标签、VXLAN 隧道、名称和地址、文本以及背景，可任意组合。您的选择会保存在此浏览器中。
  • 路径：点击两台设备，地图将只显示它们之间的线缆链路（包括途经的配线架、交换机和机柜）并缩放至该处。再次点击“路径”或按 Esc 可查看整张地图。
  • 线缆上的端口名称在放大时才显示，因此拥挤的地图也能保持清晰。它们准确显示在线缆的末端：图片的端口上，或线缆离开无端口图片的位置；它们绘制在所有线缆之上，因此不会被线缆遮挡。已被其他线缆使用的端口无法再次选择；列表会显示其线缆的去向。
  • VLAN：当地图上的交换机或路由器上报 VLAN 时，工具栏中会出现 VLAN 列表。选择一个 VLAN 后，地图只显示承载该 VLAN 的线缆，并标明带标签或不带标签；没有该 VLAN 的设备会变淡。线缆面板会列出其端口的 VLAN。
  • 线缆会标注其 VLAN 模式，例如 Access 20 或 Trunk · native 1 · 10, 20-25（图层 VLAN 标签）。VLAN 筛选器也可以只显示带标签或只显示不带标签的 VLAN。当线缆两端不一致时——Access 端口对接 Trunk，或两端的本征 VLAN 不同——线缆会显示为橙色虚线。
  • 编辑时可以手动设置线缆的 VLAN 模式：Access 及其 VLAN，或 Trunk 及其本征 VLAN 和允许的（带标签的）VLAN，可包含 20-25 这样的范围；自动使用端口上报的内容。线缆还可以承载 VXLAN VNI，线缆类别 VXLAN 隧道可手动绘制隧道。
  • 设备上报的 VXLAN 隧道显示为带有 VNI 的紫色虚线弧（图层 VXLAN 隧道）。

展示屏

在设置 → 展示屏中创建展示屏，指定其显示的地图以及切换频率。它会获得一个秘密链接，无需登录即可全屏打开这些地图——适用于监控电视。删除展示屏即可使该链接失效。

如需从某张地图而不是概览开始，请在我的帐户中将其选为起始页；登录后和点击徽标时都会打开它，菜单中的概览仍会打开概览。仪表板也可以作为起始页。

自动排列地图

编辑时，自动排列会按线缆布局整张地图：连接最多的设备（数量相同时，路由器或防火墙优先于交换机）放在最上方，连接在它下面的设备放在下一行，依此类推；机柜和虚拟化主机框会连同其内容一起移动，没有线缆的东西放在下方的网格中，手动绘制的折点会被删除。在点击保存之前不会保存任何内容；取消会将一切恢复原状。

在设备上发现的链路

WatchZit 每 15 分钟通过 SNMP（MikroTik 设备则通过 RouterOS API 检查）从设备读取连接位置，按可靠程度排序如下：

  • 邻居表——LLDP、Cisco CDP 和 MikroTik discovery：两端及其端口。如果两台设备之间存在物理端口，则只计算物理端口（不包括 VLAN、VXLAN、网桥或 VRRP 接口）。
  • 交换机的 MAC 地址表：学习到某设备 MAC 地址的端口——其自身接口的 MAC、代理上报的网卡，或路由器 ARP 表中该地址对应的 MAC（因此没有 SNMP 的打印机、摄像头和服务器也能被找到）。选用地址最少的 Access 端口；通往其他交换机的端口（邻居是交换机，或地址超过 8 个）不予选用。
  • 指明另一台设备的端口描述（接口别名，或已保存配置中的描述），例如“uplink to sw2 ether7”——如果描述中指明了端口，则使用该端口。
  • 已保存的配置（MikroTik、Cisco、FortiGate 的配置备份）：地址位于同一点对点网络（/30 或 /31）中的两台设备。

自动绘制（在“建议的链路”面板中）：地图每 15 分钟添加一次在其设备之间发现的链路；启用同时添加它们连接到的设备后，还会添加与其相连的设备，并放在它们所连接的设备旁边。从这类地图中删除的链路和设备将保持删除状态（关闭该选项后再重新开启会清除此记录）。重新读取设备会立即读取地图上的设备。
