REST API

Skripte i drugi sistemi čitaju uređaje, provere, grafike i probleme, potvrđuju probleme i zakazuju održavanje preko JSON API-ja.

Tokeni

Napravite token u Moj nalog → API tokeni: naziv i koliko dana važi. Prikazuje se samo jednom. Token radi kao vi, sa vašom ulogom (token korisnika koji samo gleda može samo da čita); opozovite ga kada više nije potreban. Neispravni tokeni se računaju kao neuspele prijave i na neko vreme blokiraju adresu.

Šaljite ga u zaglavlju; API nikad ne prihvata kolačić sesije konzole:

curl -H "Authorization: Bearer wzat_…" https://monitor.example.com:8443/api/v1/status
