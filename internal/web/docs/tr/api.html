REST API

Betikler ve diğer sistemler bir JSON API üzerinden cihazları, kontrolleri, grafikleri ve sorunları okur, sorunları üstlenir ve bakım planlar.

Belirteçler

Hesabım → API belirteçleri altında bir belirteç oluşturun: bir ad ve kaç gün geçerli olduğu. Bir kez gösterilir. Belirteç sizin adınıza, sizin rolünüzle çalışır (bir izleyicinin belirteci yalnızca okuyabilir); artık gerekmediğinde iptal edin. Başarısız belirteçler başarısız girişler gibi sayılır ve adresi bir süreliğine engeller.

Belirteci bir başlıkta gönderin; API konsolun oturum çerezini hiçbir zaman kabul etmez:

curl -H "Authorization: Bearer wzat_…" https://monitor.example.com:8443/api/v1/status

Uç noktalar

İstekYanıt
GET /api/v1/statussürüm, duruma göre cihazlar, öneme göre açık sorunlar
GET /api/v1/devicescihazlar; filtreler q, status, group
GET /api/v1/devices/{id}kontrolleri ve serilerinin kimlikleriyle bir cihaz
GET /api/v1/series/{id}?range=24hbir serinin noktaları: zaman, asgari, ortalama, azami
GET /api/v1/problemsaçık sorunlar; view=history, severity, device
POST /api/v1/problems/{id}/acküstlenme: {"note": "…"}
GET /api/v1/maintenancebakım pencereleri
POST /api/v1/maintenancebir tane planlama: {"name", "starts_at", "ends_at", "device_ids", "group_ids"}

Zamanlar RFC 3339 biçimindedir (2026-11-01T22:00:00+01:00). Hatalar, uygun bir HTTP durumuyla {"error": "…"} şeklindedir. Değişiklikler belirtecin adıyla denetim günlüğüne yazılır.
