Instalar o servidor

O WatchZit corre num servidor Linux de 64 bits (basta uma pequena máquina virtual) com PostgreSQL. O script de instalação configura tudo; também existem pacotes e uma imagem de appliance pronta a usar.

Requisitos

  • Debian 12+, Ubuntu 22.04+, AlmaLinux ou Rocky Linux 9+, x86-64.
  • 2 núcleos de CPU e 2 GB de memória para algumas centenas de dispositivos; 10 GB de disco (as medições são guardadas de forma compacta: uma hora de tempos de ping ocupa cerca de 100 bytes).
  • Portas: 8443 para a consola (as suas redes de administração), 8444 para os agentes (apenas onde houver agentes).

Script de instalação

Como root no servidor:

curl -fsSL https://github.com/Max-Zit/watchzit/releases/latest/download/install.sh | sudo sh

O script instala o PostgreSQL, transfere a versão mais recente, verifica a sua assinatura com a chave de versões do WatchZit, instala o pacote, cria a base de dados com uma palavra-passe aleatória, abre as portas no firewalld ou no ufw e inicia o serviço. No fim mostra o endereço da consola e o token de configuração.

Opções: --version X (uma versão específica), --db postgres://… (uma base de dados existente em vez de um PostgreSQL local), --no-auto-updates (não ativar as atualizações de segurança do sistema operativo), --source URL (um espelho ou uma pasta local com os ficheiros da versão). Executar o script novamente atualiza o WatchZit e mantém os dados.

Pacotes

Cada versão tem um .deb e um .rpm do servidor. Instalam o programa, os serviços systemd e os instaladores dos agentes; defina WATCHZIT_DB em /etc/watchzit/server.env e inicie o watchzit-server.

Appliance

A appliance é uma imagem pronta a usar (Debian com WatchZit, PostgreSQL e atualizações de segurança automáticas). Importe-a no VMware, Proxmox ou Hyper-V, inicie-a e siga o menu no seu ecrã: mostra o endereço da consola e o token de configuração, e configura a rede.

Imagens: OVA (VMware ESXi, Workstation, VirtualBox), qcow2 (Proxmox, KVM), VHDX (Hyper-V geração 1) e uma ISO que instala a appliance numa VM nova ou num servidor físico (apaga o primeiro disco). Atribua-lhe 2 CPUs, 2 GB de memória e um disco de 16 GB ou mais; um disco maior é aproveitado automaticamente. Inicie sessão no seu ecrã como wzadmin com a palavra-passe inicial watchzit; tem de escolher uma nova de imediato. O menu configura a rede (DHCP ou um endereço fixo), o nome do servidor, o fuso horário e o SSH (ligado ou desligado, porta), e define uma nova palavra-passe para um utilizador da consola, como admin (levantando todos os bloqueios de início de sessão). A rede, o SSH, as atualizações do sistema operativo e um certificado confiável também podem ser configurados na consola (consulte Utilizadores, configurações e atualizações). O SSH não permite o início de sessão como root.

Primeiro início de sessão

  1. Abra https://<servidor>:8443. O navegador avisa uma vez sobre o certificado autoassinado; aceite-o.
  2. Introduza o token de configuração e crie o primeiro administrador.
  3. Leia o código QR com uma aplicação de autenticação (o início de sessão em dois passos é obrigatório) e guarde os códigos de recuperação.

Ficheiros e serviços

CaminhoO quê
/etc/watchzit/server.envEndereço da base de dados e origem das atualizações.
/var/lib/watchzitCertificados, a chave secreta (faça cópia de segurança dela juntamente com a base de dados), transferências, logs.
watchzit-server.serviceO servidor. journalctl -u watchzit-server mostra o seu log.
watchzit-helper.pathO auxiliar root para atualizações, fuso horário e reinícios a partir da consola.

Faça cópia de segurança da base de dados e de /var/lib/watchzit/secret.key: as palavras-passe guardadas (SNMP, bases de dados, canais) estão cifradas com ela.
