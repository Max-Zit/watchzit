Resolução de problemas e perguntas frequentes

O ping indica "ICMP is not allowed"

O servidor precisa de permissão para enviar ICMP. O serviço instalado pelo pacote tem-na (CAP_NET_RAW). Noutros casos, conceda-a com setcap cap_net_raw+ep /usr/bin/watchzit-server ou permita o ping sem privilégios: sysctl net.ipv4.ping_group_range="0 2147483647".

O SNMP indica "no answer"

  • Verifique no perfil a community ou o utilizador SNMPv3, os protocolos e as palavras-passe.
  • Autorize o endereço do servidor WatchZit no dispositivo (muitos dispositivos só respondem a gestores listados) e UDP 161 nas firewalls.
  • A mensagem indica-o quando um utilizador v3 é desconhecido ou a palavra-passe está errada.

Um agente não se liga

  • O computador tem de chegar à porta dos agentes 8444 do servidor; verifique Configurações → Rede e acesso (redes autorizadas, endereço público para agentes).
  • Windows: Get-Service WatchZitAgent e o log em C:\ProgramData\WatchZit Agent. Linux: journalctl -u watchzit-agent.
  • "the server does not know this agent": o dispositivo foi removido; registe-o novamente com um novo código.

As notificações não chegam

  • Envie um teste a partir de Configurações → Notificações; a lista de canais mostra o último erro.
  • Os problemas em manutenção ou atrás de um dispositivo em baixo não são enviados; verifique a gravidade mínima do canal.

Fiquei sem acesso

Após demasiados inícios de sessão falhados, o endereço fica bloqueado durante algum tempo. No servidor: watchzit-server --unblock-ip all. Se as redes autorizadas o excluírem: watchzit-server --reset-allowlist.

Onde estão os logs?

journalctl -u watchzit-server e /var/lib/watchzit/logs/server.log; o auxiliar de atualizações escreve em /var/log/watchzit-helper/helper.log. Configurações → Diagnóstico mostra as linhas mais recentes e fornece um ZIP sem segredos para enviar ao suporte.

Perguntas frequentes

Os dispositivos precisam de um agente? Não. As verificações de ping, portas, SNMP, web, DNS, bases de dados e APIs correm a partir do servidor; o agente acrescenta o que só o próprio computador sabe.

Quantos dispositivos? Um servidor consulta milhares de verificações por minuto; as medições são comprimidas, por isso um ano de dados continua a ocupar pouco.
