Primeiros passos

O WatchZit é um sistema de monitorização de redes e dispositivos alojado no seu próprio servidor. Um mapa de rede em tempo real mostra o que está ligado a quê e como está a funcionar; por trás dele há verificações, gráficos, alertas, painéis e relatórios — no seu próprio servidor, sob a licença AGPL-3.0.

O que o WatchZit faz

Como funciona

  • O servidor corre em Linux com PostgreSQL. Tem duas portas: a consola (interface web e API REST, TCP 8443) e o ponto de acesso dos agentes (TCP 8444).
  • O próprio servidor consulta os dispositivos (ping, TCP, SNMP, HTTP, bases de dados, APIs). Para isso não é preciso instalar nada nos dispositivos.
  • Os agentes são opcionais. Ligam-se para fora à porta dos agentes e comunicam a cada minuto; os computadores não precisam de portas abertas.
  • Todas as alterações na consola ficam registadas no log de auditoria à prova de adulteração.

Primeiros passos

  1. Instale o servidor — consulte Instalar o servidor.
  2. Crie o primeiro administrador com o token de configuração mostrado pelo instalador e configure o início de sessão em dois passos com uma aplicação de autenticação.
  3. Adicione dispositivos em Dispositivos: basta um nome e um endereço; o ping é adicionado automaticamente. Adicione um perfil SNMP para ler as interfaces e o tráfego.
  4. Desenhe um mapa em Mapas e ligue os dispositivos porta a porta.
  5. Configure as notificações em Configurações → Notificações; os gatilhos incorporados já vigiam dispositivos em baixo, discos cheios e certificados a expirar.

Por predefinição, a consola só é acessível a partir de redes privadas. Mantenha-a assim e abra apenas a porta dos agentes (8444) onde os agentes precisarem dela.
