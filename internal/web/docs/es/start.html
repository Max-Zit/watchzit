Primeros pasos

WatchZit es un sistema autoalojado de supervisión de redes y dispositivos. Un mapa de red en vivo muestra qué está conectado con qué y en qué estado se encuentra; detrás hay comprobaciones, gráficos, alertas, paneles e informes, todo en su propio servidor y bajo la licencia AGPL-3.0.

Cómo funciona

  • El servidor funciona en Linux con PostgreSQL. Tiene dos puertos: la consola (interfaz web y API REST, TCP 8443) y el punto de acceso de agentes (TCP 8444).
  • El servidor sondea los dispositivos por sí mismo (ping, TCP, SNMP, HTTP, bases de datos, API). Para ello no hace falta instalar nada en los dispositivos.
  • Los agentes son opcionales. Se conectan hacia fuera al puerto de agentes e informan cada minuto; los equipos no necesitan puertos abiertos.
  • Cada cambio en la consola se escribe en el registro de auditoría, protegido contra manipulaciones.

Primeros pasos

  1. Instale el servidor: consulte Instalar el servidor.
  2. Cree el primer administrador con el token de configuración que muestra el instalador y configure el inicio de sesión en dos pasos con una aplicación de autenticación.
  3. Añada dispositivos en Dispositivos: basta con un nombre y una dirección; el ping se añade automáticamente. Añada un perfil SNMP para leer las interfaces y el tráfico.
  4. Dibuje un mapa en Mapas y conecte los dispositivos de puerto a puerto.
  5. Configure las notificaciones en Configuración → Notificaciones; los disparadores integrados ya vigilan los dispositivos caídos, los discos llenos y los certificados a punto de caducar.

De forma predeterminada, la consola solo es accesible desde redes privadas. Manténgalo así y abra únicamente el puerto de agentes (8444) donde los agentes lo necesiten.
