Instalar el servidor

WatchZit funciona en un servidor Linux de 64 bits (basta con una máquina virtual pequeña) con PostgreSQL. El script de instalación lo prepara todo; también hay paquetes y una imagen de appliance lista para usar.

Requisitos

  • Debian 12+, Ubuntu 22.04+, AlmaLinux o Rocky Linux 9+, x86-64.
  • 2 núcleos de CPU y 2 GB de memoria para unos cientos de dispositivos; 10 GB de disco (las mediciones se guardan de forma compacta: una hora de tiempos de ping ocupa unos 100 bytes).
  • Puertos: 8443 para la consola (sus redes de administración), 8444 para los agentes (solo donde haya agentes).

Script de instalación

Como root en el servidor:

curl -fsSL https://github.com/Max-Zit/watchzit/releases/latest/download/install.sh | sudo sh

El script instala PostgreSQL, descarga la versión más reciente, comprueba su firma con la clave de publicación de WatchZit, instala el paquete, crea la base de datos con una contraseña aleatoria, abre los puertos en firewalld o ufw e inicia el servicio. Al final muestra la dirección de la consola y el token de configuración.

Opciones: --version X (una versión concreta), --db postgres://… (una base de datos existente en lugar de un PostgreSQL local), --no-auto-updates (no activar las actualizaciones de seguridad del sistema operativo), --source URL (un espejo o una carpeta local con los archivos de la versión). Si vuelve a ejecutar el script, WatchZit se actualiza y conserva los datos.

Paquetes

Cada versión incluye un .deb y un .rpm del servidor. Instalan el programa, los servicios de systemd y los instaladores de agentes; defina WATCHZIT_DB en /etc/watchzit/server.env e inicie watchzit-server.

Appliance

El appliance es una imagen lista para usar (Debian con WatchZit, PostgreSQL y actualizaciones de seguridad automáticas). Impórtelo en VMware, Proxmox o Hyper-V, inícielo y siga el menú de su pantalla: muestra la dirección de la consola y el token de configuración, y configura la red.

Imágenes: OVA (VMware ESXi, Workstation, VirtualBox), qcow2 (Proxmox, KVM), VHDX (Hyper-V generación 1) y una ISO que instala el appliance en una VM nueva o en un servidor físico (borra el primer disco). Asígnele 2 CPU, 2 GB de memoria y un disco de 16 GB o más; un disco mayor se aprovecha automáticamente. Inicie sesión en su pantalla como wzadmin con la contraseña inicial watchzit; deberá elegir una nueva de inmediato. El menú configura la red (DHCP o una dirección fija), el nombre del servidor, la zona horaria y SSH (activado o desactivado, puerto), y establece una contraseña nueva para un usuario de la consola, como admin (y levanta todos los bloqueos de inicio de sesión). La red, SSH, las actualizaciones del sistema operativo y un certificado de confianza también se pueden configurar en la consola (consulte Usuarios, configuración y actualizaciones). SSH no permite iniciar sesión como root.

Primer inicio de sesión

  1. Abra https://<servidor>:8443. El navegador avisa una vez del certificado autofirmado; acéptelo.
  2. Introduzca el token de configuración y cree el primer administrador.
  3. Escanee el código QR con una aplicación de autenticación (el inicio de sesión en dos pasos es obligatorio) y guarde los códigos de recuperación.

Archivos y servicios

RutaQué es
/etc/watchzit/server.envDirección de la base de datos y origen de las actualizaciones.
/var/lib/watchzitCertificados, la clave secreta (haga una copia junto con la base de datos), descargas, registros.
watchzit-server.serviceEl servidor. journalctl -u watchzit-server muestra su registro.
watchzit-helper.pathEl asistente con permisos de root para las actualizaciones, la zona horaria y los reinicios desde la consola.

Haga copia de seguridad de la base de datos y de /var/lib/watchzit/secret.key: las contraseñas guardadas (SNMP, bases de datos, canales) están cifradas con ella.
