Solución de problemas y preguntas frecuentes

Ping indica "ICMP is not allowed"

El servidor necesita permiso para enviar ICMP. El servicio empaquetado lo tiene (CAP_NET_RAW). En otros casos, concédaselo con setcap cap_net_raw+ep /usr/bin/watchzit-server o permita el ping sin privilegios: sysctl net.ipv4.ping_group_range="0 2147483647".

SNMP indica "sin respuesta"

  • Compruebe la comunidad o el usuario SNMPv3, los protocolos y las contraseñas del perfil.
  • Permita la dirección del servidor WatchZit en el dispositivo (muchos dispositivos solo responden a los gestores de su lista) y UDP 161 en los cortafuegos.
  • El mensaje lo indica cuando un usuario v3 es desconocido o la contraseña es incorrecta.

Un agente no se conecta

  • El equipo debe llegar al puerto de agentes 8444 del servidor; revise Configuración → Red y acceso (redes permitidas, dirección pública para agentes).
  • Windows: Get-Service WatchZitAgent y el registro en C:\ProgramData\WatchZit Agent. Linux: journalctl -u watchzit-agent.
  • "the server does not know this agent": el dispositivo se eliminó; inscríbalo de nuevo con un código nuevo.

No llegan las notificaciones

  • Envíe una prueba desde Configuración → Notificaciones; la lista de canales muestra el último error.
  • Los problemas en mantenimiento o detrás de un dispositivo caído no se envían; revise la gravedad mínima del canal.

Me he quedado sin acceso

Tras demasiados inicios de sesión fallidos, la dirección queda bloqueada durante un tiempo. En el servidor: watchzit-server --unblock-ip all. Si las redes permitidas le excluyen: watchzit-server --reset-allowlist.

¿Dónde están los registros?

journalctl -u watchzit-server y /var/lib/watchzit/logs/server.log; el asistente de actualizaciones escribe en /var/log/watchzit-helper/helper.log. Configuración → Diagnóstico muestra las líneas más recientes y ofrece un ZIP sin secretos para enviar al soporte.

Preguntas frecuentes

¿Necesitan los dispositivos un agente? No. Las comprobaciones de ping, puertos, SNMP, web, DNS, bases de datos y API se ejecutan desde el servidor; el agente añade lo que solo sabe el propio equipo.

¿Cuántos dispositivos? Un servidor sondea miles de comprobaciones por minuto; las mediciones se comprimen, así que un año de datos ocupa poco.
