Открытие устройств

Со страницы устройства или из боковой панели карты вы открываете устройство нужной программой: его веб-интерфейсом, SSH, удалённым рабочим столом, WinBox, VNC или собственными инструментами.

MaxZit Launcher

Браузер не может запускать программы, поэтому это делает небольшая программа для Windows — MaxZit Launcher. Установите её один раз на каждый компьютер со страницы Launcher — установщик (MSI) с коротким мастером установки добавляет её в список приложений с собственным значком, откуда её можно снова удалить; она устанавливается для вашего пользователя Windows без прав администратора — и нажмите Связать этот компьютер. Launcher показывает отпечаток сервера; он должен совпадать с отпечатком на странице.

После этого работают кнопки Открыть в. Если консоль переезжает на другой адрес (или восстанавливается из резервной копии в другом месте), снова нажмите Связать этот компьютер: Launcher узнает её по ключу и предложит использовать новый адрес. В первый раз браузер спросит, можно ли открыть Launcher; разрешите.

Тот же Launcher обслуживает и PassZit: в меню расширения PassZit нажмите Pair with the MaxZit Launcher и подтвердите в собственном окне Launcher. После этого PassZit открывает удалённый рабочий стол, SSH, WinSCP, WinBox, VNC и Telnet с учётными данными из хранилища: удалённый рабочий стол — через учётные данные Windows, которые существуют лишь несколько секунд, пароль или ключ SSH — через файл, доступный для чтения только вам, который удаляется сразу после запуска. Launcher заменяет прежние WatchZit Launcher и passzit-helper: при установке он перенимает их настройки и связи. Когда PassZit связан, а адрес консоли входит в число его доверенных консолей MaxZit, кнопки Открыть в в WatchZit открывают устройство с уже выполненным входом по подходящим учётным данным из хранилища; без PassZit или без учётных данных для этого устройства они работают как прежде. Консоль сообщает PassZit только инструмент, адрес, порт, имя пользователя и имя устройства — никогда не пароль. Рядом с кнопками Открыть в маленький значок PassZit показывает, что PassZit разблокирован и выполнит вход; PassZit заблокирован означает, что сначала его нужно разблокировать. Если PassZit для этой консоли не настроен, небольшая подсказка объясняет, как это разрешить; Больше не показывать скрывает её в этом браузере.

Как обеспечивается безопасность

  • Каждый щелчок даёт ссылку, подписанную вашим сервером, которая действует минуту и срабатывает один раз; Launcher принимает ссылки только от связанных вами серверов.
  • Адреса и имена пользователей проверяются по строгим наборам символов; программы запускаются со списком аргументов, никогда через оболочку.
  • Пароли никогда не сохраняются и не передаются: их запрашивает сама программа.
  • Прежде чем программа, добавленная вашим администратором, запустится в первый раз, Launcher спросит вас.

Программы в других местах: впишите их пути в %APPDATA%\MaxZit Launcher\launcher.json. Без Launcher удалённый рабочий стол всё равно работает: кнопка .rdp загружает файл, который открывает Windows.

Собственные инструменты

В разделе Настройки → Инструменты администраторы отключают встроенные инструменты, ограничивают их типами устройств и добавляют собственные: путь к программе (например, %ProgramFiles%\Mozilla Firefox\firefox.exe) и аргументы с {host}, {port}, {user} и {name}. Имя пользователя и порты для каждого устройства задаются в разделе Удалённый доступ устройства; там же снимите отметку с инструментов, которых у устройства нет (у сервера Proxmox или Linux нет удалённого рабочего стола), или отметьте инструмент, который его тип по умолчанию не получает; после этого кнопки на странице устройства и на картах показывают только отмеченные инструменты.

Ссылки на каждом устройстве

Также в разделе Настройки → Инструменты параметр Ссылки на каждом устройстве добавляет на страницу каждого устройства кнопки, которые открывают устройство в другой программе в браузере, например в RMMZit или BackupZit. Укажите имя и адрес; {name}, {address} и {id} заменяются именем, адресом и номером устройства, например https://rmm.example.com:8443/devices?q={name}. Принимаются только адреса http:// и https://.
