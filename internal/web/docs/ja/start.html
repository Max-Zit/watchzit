はじめに

WatchZit は、自社のサーバーで運用するネットワーク・デバイス監視システムです。ライブのネットワークマップで、何が何につながっていて、どのような状態にあるかがひと目でわかります。その背後にはチェック、グラフ、アラート、ダッシュボード、レポートがあり、すべてが AGPL-3.0 ライセンスのもと、お使いのサーバー上で動作します。

WatchZit でできること

分野内容
ネットワークマップ実際の機器の画像、ラック、ポート間のケーブルでネットワークを描画できます。マップにはライブの状態とトラフィックが表示されます。ネットワークマップ
チェックPing、TCP ポート、Web ページ、TLS 証明書、DNS、PostgreSQL と MySQL、SNMP（v1/v2c/v3：インターフェース、CPU、メモリー、ディスク、任意の OID）、MikroTik RouterOS API、任意の JSON API の値を監視します。デバイスとチェック
エージェントWindows と Linux 向けの小さなオプションのエージェントが、CPU、メモリー、ディスク、インターフェース、選択したサービスを報告します。エージェント
アラートトリガーが問題を発生させます。依存関係、メンテナンス期間、対応済みの記録によって不要な通知を抑えます。通知はメール、Webhook、Slack、Teams で送信できます。問題とアラート
グラフ、ダッシュボード、レポートあらゆる値の 1 時間から 1 年までのグラフ、壁掛けモニター向けのダッシュボード、可用性レポートを利用できます。ダッシュボードとレポート
デバイスを開くデバイスの Web ページ、SSH、リモート デスクトップ、WinBox、独自のツールをワンクリックで開けます。デバイスを開く

仕組み

  • サーバーは Linux 上で PostgreSQL とともに動作します。ポートは 2 つあります。コンソール（Web インターフェースと REST API、TCP 8443）とエージェント接続先（TCP 8444）です。
  • サーバーはデバイスを自らポーリングします（Ping、TCP、SNMP、HTTP、データベース、API）。そのためにデバイスへ何かをインストールする必要はありません。
  • エージェントはオプションです。エージェントはエージェント用ポートへ外向きに接続して 1 分ごとに報告するため、コンピューター側でポートを開ける必要はありません。
  • コンソールでのすべての変更は、改ざんを検知できる監査ログに記録されます。

最初の手順

  1. サーバーをインストールします — サーバーのインストールを参照してください。
  2. インストーラーが表示するセットアップトークンを使って最初の管理者を作成し、認証アプリによる 2 要素サインインを設定します。
  3. デバイスでデバイスを追加します。名前とアドレスだけで十分で、Ping は自動的に追加されます。インターフェースとトラフィックを読み取るには SNMP プロファイルを追加します。
  4. マップでマップを描き、デバイスをポート同士で接続します。
  5. 設定 → 通知で通知を設定します。組み込みのトリガーが、ダウンしたデバイス、満杯のディスク、期限切れが近い証明書をすでに監視しています。

既定では、コンソールにはプライベートネットワークからのみアクセスできます。この設定は変えずに、エージェントが必要とする場所でのみエージェント用ポート（8444）を開けてください。
