サーバーのインストール

WatchZit は、PostgreSQL を備えた 64 ビットの Linux サーバー（小さな仮想マシンで十分です）で動作します。インストールスクリプトがすべてをセットアップします。パッケージや、すぐに使えるアプライアンスイメージも用意されています。

要件

  • Debian 12 以降、Ubuntu 22.04 以降、AlmaLinux または Rocky Linux 9 以降、x86-64。
  • 数百台のデバイスであれば CPU 2 コアとメモリー 2 GB、ディスク 10 GB（測定値はコンパクトに保存されます。Ping 時間 1 時間分で約 100 バイトです）。
  • ポート：コンソール用に 8443（管理用ネットワーク向け）、エージェント用に 8444（エージェントがある場所のみ）。

インストールスクリプト

サーバー上で root として実行します。

curl -fsSL https://github.com/Max-Zit/watchzit/releases/latest/download/install.sh | sudo sh

スクリプトは PostgreSQL をインストールし、最新のリリースをダウンロードして、WatchZit のリリースキーで署名を確認し、パッケージをインストールします。さらに、ランダムなパスワードでデータベースを作成し、firewalld または ufw でポートを開けて、サービスを起動します。最後にコンソールのアドレスとセットアップトークンを表示します。

オプション：--version X（指定したリリース）、--db postgres://…（ローカルの PostgreSQL の代わりに既存のデータベースを使用）、--no-auto-updates（OS のセキュリティ更新を有効にしない）、--source URL（リリースファイルを置いたミラーまたはローカルフォルダー）。スクリプトをもう一度実行すると、データを保持したまま WatchZit を更新します。

パッケージ

各リリースには、サーバーの .deb と .rpm があります。これらはプログラム、systemd サービス、エージェントのインストーラーをインストールします。/etc/watchzit/server.env で WATCHZIT_DB を設定し、watchzit-server を起動してください。

アプライアンス

アプライアンスは、すぐに使えるイメージです（WatchZit、PostgreSQL、自動セキュリティ更新を備えた Debian）。VMware、Proxmox、Hyper-V にインポートして起動し、画面のメニューに従ってください。メニューにはコンソールのアドレスとセットアップトークンが表示され、ネットワークも設定できます。

イメージ：OVA（VMware ESXi、Workstation、VirtualBox）、qcow2（Proxmox、KVM）、VHDX（Hyper-V 第 1 世代）、および新しい VM や物理サーバーにアプライアンスをインストールする ISO（最初のディスクは消去されます）。CPU 2 個、メモリー 2 GB、16 GB 以上のディスクを割り当ててください。より大きなディスクは自動的に使用されます。画面で wzadmin として初期パスワード watchzit でサインインすると、すぐに新しいパスワードを設定するよう求められます。メニューでは、ネットワーク（DHCP または固定アドレス）、サーバー名、タイムゾーン、SSH（オン／オフ、ポート）を設定でき、admin などのコンソールユーザーに新しいパスワードを設定することもできます（その際、すべてのサインインブロックが解除されます）。ネットワーク、SSH、OS の更新、信頼された証明書はコンソールでも設定できます（「ユーザー、設定、更新」を参照）。SSH では root でのサインインはできません。

最初のサインイン

  1. https://<サーバー>:8443 を開きます。ブラウザーが自己署名証明書について一度だけ警告するので、受け入れます。
  2. セットアップトークンを入力し、最初の管理者を作成します。
  3. 認証アプリで QR コードをスキャンし（2 要素サインインは必須です）、リカバリーコードを保管します。

ファイルとサービス

パス内容
/etc/watchzit/server.envデータベースのアドレスと更新元。
/var/lib/watchzit証明書、秘密鍵（データベースと一緒にバックアップしてください）、ダウンロード、ログ。
watchzit-server.serviceサーバー本体。journalctl -u watchzit-server でログを表示できます。
watchzit-helper.pathコンソールからの更新、タイムゾーン変更、再起動を行う root ヘルパー。

データベースと /var/lib/watchzit/secret.key をバックアップしてください。保存されたパスワード（SNMP、データベース、通知チャネル）はこの鍵で暗号化されています。
