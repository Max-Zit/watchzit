デバイスを開く

デバイスページやマップのサイドパネルから、適切なプログラムでデバイスを開けます：Web インターフェース、SSH、リモート デスクトップ、WinBox、VNC、または独自のツールです。

MaxZit Launcher

ブラウザーはプログラムを起動できないため、小さな Windows プログラムがそれを担います：MaxZit Launcher です。Launcher ページから、コンピューターごとに一度インストールします — 短いセットアップウィザード付きのインストーラー（MSI）がアイコン付きで「アプリ」に登録し、そこから再び削除することもできます。インストールは Windows ユーザー単位で行われ、管理者権限は不要です — その後、このコンピューターをペアリングをクリックします。Launcher にはサーバーのフィンガープリントが表示されるので、ページに表示されたものと一致することを確認してください。

これで次で開くボタンが使えるようになります。コンソールが別のアドレスに移った場合（または別の場所でバックアップから復元された場合）は、もう一度このコンピューターをペアリングをクリックします。Launcher は鍵によってコンソールを認識し、新しいアドレスを使うかどうかを尋ねます。初回は、ブラウザーが Launcher を開いてよいか確認するので、許可してください。

同じ Launcher は PassZit にも使われます：PassZit 拡張機能のメニューで MaxZit Launcher とペアリングをクリックし、Launcher 自身のウィンドウで同意します。これにより PassZit は、保管庫のログイン情報を使ってリモート デスクトップ、SSH、WinSCP、WinBox、VNC、Telnet を開きます — リモート デスクトップは数秒間だけ存在する Windows 資格情報を通じて、SSH のパスワードや鍵は本人だけが読めるファイルを通じて渡され、そのファイルは起動直後に削除されます。この Launcher は、以前の WatchZit Launcher と passzit-helper に代わるものです。インストールすると、それらの設定とペアリングが引き継がれます。PassZit がペアリングされていて、コンソールのアドレスが PassZit の信頼済み MaxZit コンソールの 1 つである場合、WatchZit の次で開くボタンは、保管庫内の一致するログイン情報でサインインした状態で開きます。PassZit がない場合や、そのデバイスのログイン情報がない場合は、これまでどおりに開きます。コンソールが PassZit に伝えるのは、ツール、アドレス、ポート、ユーザー名、デバイス名だけで、パスワードは決して伝えません。次で開くボタンの横にある小さな PassZit バッジは、PassZit のロックが解除されていてサインインを行うことを示します。PassZit ロック中は、先にロックを解除する必要があることを意味します。このコンソールで PassZit が使われていない場合は、許可する方法を説明する小さなヒントが表示されます。今後表示しないで、このブラウザーでは非表示になります。

安全性の仕組み

  • クリックのたびに、サーバーが署名した、1 分間有効で 1 回だけ使えるリンクが発行されます。Launcher は、ペアリングしたサーバーからのリンクだけを受け付けます。
  • アドレスとユーザー名は厳格な文字セットで検証されます。プログラムは引数リストで起動され、シェルを経由することはありません。
  • パスワードは保存も送信もされません。プログラム側でパスワードを尋ねます。
  • 管理者が追加したプログラムを初めて実行する前に、Launcher が確認を求めます。

独自のツール

設定 → ツールでは、管理者が組み込みツールをオフにしたり、デバイスの種類ごとに制限したり、独自のツールを追加したりできます：プログラムのパス（例：%ProgramFiles%\Mozilla Firefox\firefox.exe）と、{host}、{port}、{user}、{name} を含む引数を指定します。デバイスごとのユーザー名とポートはデバイスのリモート アクセスで設定します。そこでは、デバイスにないツールのチェックを外したり（Proxmox や Linux サーバーにはリモート デスクトップはありません）、その種類では既定で付かないツールにチェックを入れたりもできます。デバイスページとマップ上のボタンには、チェックを入れたツールだけが表示されます。

すべてのデバイスのリンク

同じく設定 → ツールのすべてのデバイスのリンクでは、ブラウザー上の別のプログラム（たとえば RMMZit や BackupZit）でデバイスを開くボタンを、すべてのデバイスページに追加します。名前とアドレスを指定します。{name}、{address}、{id} は、デバイスの名前、アドレス、番号に置き換えられます。例：https://rmm.example.com:8443/devices?q={name}。使えるのは http:// と https:// のアドレスだけです。
