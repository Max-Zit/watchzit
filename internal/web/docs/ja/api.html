REST API

スクリプトや他のシステムは、JSON API を使って、デバイス、チェック、グラフ、問題を読み取り、問題に対応し、メンテナンスを計画できます。

トークン

マイ アカウント → API トークンでトークンを作成します：名前と有効日数を指定します。トークンは一度だけ表示されます。トークンはあなた自身として、あなたのロールで動作します（閲覧者のトークンは読み取りのみ可能です）。不要になったら失効させてください。失敗したトークンは失敗したサインインと同じように数えられ、一定時間そのアドレスをブロックします。

トークンはヘッダーで送信します。API はコンソールのセッション Cookie を一切受け付けません。

curl -H "Authorization: Bearer wzat_…" https://monitor.example.com:8443/api/v1/status

エンドポイント

リクエスト応答
GET /api/v1/statusバージョン、状態別のデバイス、重大度別の未解決の問題
GET /api/v1/devicesデバイス。フィルター q、status、group
GET /api/v1/devices/{id}デバイスとそのチェック、およびそれらの系列の ID
GET /api/v1/series/{id}?range=24h系列のポイント：時刻、最小値、平均値、最大値
GET /api/v1/problems未解決の問題。view=history、severity、device
POST /api/v1/problems/{id}/ack対応済みにする：{"note": "…"}
GET /api/v1/maintenanceメンテナンス期間
POST /api/v1/maintenanceメンテナンス期間を計画：{"name", "starts_at", "ends_at", "device_ids", "group_ids"}

時刻は RFC 3339 形式です（2026-11-01T22:00:00+01:00）。エラーは対応する HTTP ステータスとともに {"error": "…"} として返されます。変更は、トークンの名前とともに監査ログに記録されます。
