Risoluzione dei problemi e FAQ

Il ping indica "ICMP is not allowed"

Il server deve avere il permesso di inviare ICMP. Il servizio pacchettizzato ce l'ha (CAP_NET_RAW). Altrove, concediglielo con setcap cap_net_raw+ep /usr/bin/watchzit-server oppure consenti il ping non privilegiato: sysctl net.ipv4.ping_group_range="0 2147483647".

SNMP indica "nessuna risposta"

  • Controlla nel profilo la community o l'utente SNMPv3, i protocolli e le password.
  • Consenti sul dispositivo l'indirizzo del server WatchZit (molti dispositivi rispondono solo ai manager elencati) e UDP 161 sui firewall.
  • Il messaggio lo segnala quando un utente v3 è sconosciuto o la password è errata.

Un agente non si collega

  • Il computer deve raggiungere la porta degli agenti 8444 del server; controlla Impostazioni → Rete e accesso (reti consentite, indirizzo pubblico per gli agenti).
  • Windows: Get-Service WatchZitAgent e il log in C:\ProgramData\WatchZit Agent. Linux: journalctl -u watchzit-agent.
  • "the server does not know this agent": il dispositivo è stato rimosso; registralo di nuovo con un nuovo codice.

Le notifiche non arrivano

  • Invia una prova da Impostazioni → Notifiche; l'elenco dei canali mostra l'ultimo errore.
  • I problemi in manutenzione o dietro un dispositivo non attivo non vengono inviati; controlla la gravità minima del canale.

Mi sono chiuso fuori

Dopo troppi accessi falliti l'indirizzo viene bloccato per un po'. Sul server: watchzit-server --unblock-ip all. Se le reti consentite ti escludono: watchzit-server --reset-allowlist.

Dove sono i log?

journalctl -u watchzit-server e /var/lib/watchzit/logs/server.log; l'helper degli aggiornamenti scrive /var/log/watchzit-helper/helper.log. Impostazioni → Diagnostica mostra le righe più recenti e fornisce uno ZIP senza segreti da inviare all'assistenza.

FAQ

I dispositivi hanno bisogno di un agente? No. I controlli di ping, porte, SNMP, web, DNS, database e API partono dal server; l'agente aggiunge ciò che solo il computer stesso conosce.

Quanti dispositivi? Un server esegue migliaia di controlli al minuto; le misure sono compresse, quindi un anno di dati occupa poco spazio.
