Installare il server

WatchZit gira su un server Linux a 64 bit (basta una piccola macchina virtuale) con PostgreSQL. Lo script di installazione prepara tutto; sono disponibili anche pacchetti e un'immagine appliance pronta all'uso.

Requisiti

  • Debian 12+, Ubuntu 22.04+, AlmaLinux o Rocky Linux 9+, x86-64.
  • 2 core CPU e 2 GB di memoria per qualche centinaio di dispositivi; 10 GB di disco (le misure sono salvate in modo compatto: un'ora di tempi di ping occupa circa 100 byte).
  • Porte: 8443 per la console (le tue reti di amministrazione), 8444 per gli agenti (solo dove ci sono agenti).

Script di installazione

Come root sul server:

curl -fsSL https://github.com/Max-Zit/watchzit/releases/latest/download/install.sh | sudo sh

Lo script installa PostgreSQL, scarica la versione più recente, ne verifica la firma con la chiave di rilascio di WatchZit, installa il pacchetto, crea il database con una password casuale, apre le porte in firewalld o ufw e avvia il servizio. Alla fine mostra l'indirizzo della console e il token di configurazione.

Opzioni: --version X (una versione specifica), --db postgres://… (un database esistente invece di un PostgreSQL locale), --no-auto-updates (non attivare gli aggiornamenti di sicurezza del sistema operativo), --source URL (un mirror o una cartella locale con i file della versione). Eseguendo di nuovo lo script, WatchZit si aggiorna e conserva i dati.

Pacchetti

Ogni versione include un .deb e un .rpm del server. Installano il programma, i servizi systemd e gli installer degli agenti; imposta WATCHZIT_DB in /etc/watchzit/server.env e avvia watchzit-server.

Appliance

L'appliance è un'immagine pronta all'uso (Debian con WatchZit, PostgreSQL e aggiornamenti di sicurezza automatici). Importala in VMware, Proxmox o Hyper-V, avviala e segui il menu sul suo schermo: mostra l'indirizzo della console e il token di configurazione, e imposta la rete.

Immagini: OVA (VMware ESXi, Workstation, VirtualBox), qcow2 (Proxmox, KVM), VHDX (Hyper-V generazione 1) e una ISO che installa l'appliance su una nuova VM o su un server fisico (cancella il primo disco). Assegnale 2 CPU, 2 GB di memoria e un disco di almeno 16 GB; un disco più grande viene usato automaticamente. Accedi sul suo schermo come wzadmin con la password iniziale watchzit; dovrai sceglierne subito una nuova. Il menu imposta la rete (DHCP o un indirizzo fisso), il nome del server, il fuso orario e SSH (attivo o no, porta), e imposta una nuova password per un utente della console come admin (rimuovendo tutti i blocchi di accesso). Rete, SSH, aggiornamenti del sistema operativo e un certificato attendibile si possono impostare anche nella console (vedi Utenti, impostazioni e aggiornamenti). SSH non consente l'accesso come root.

Primo accesso

  1. Apri https://<server>:8443. Il browser avvisa una volta del certificato autofirmato; accettalo.
  2. Inserisci il token di configurazione e crea il primo amministratore.
  3. Scansiona il codice QR con un'app di autenticazione (l'accesso a due fattori è obbligatorio) e conserva i codici di recupero.

File e servizi

PercorsoCosa
/etc/watchzit/server.envIndirizzo del database e origine degli aggiornamenti.
/var/lib/watchzitCertificati, la chiave segreta (salvala insieme al database), download, log.
watchzit-server.serviceIl server. journalctl -u watchzit-server ne mostra il log.
watchzit-helper.pathL'helper con privilegi di root per aggiornamenti, fuso orario e riavvii dalla console.

Fai il backup del database e di /var/lib/watchzit/secret.key: le password salvate (SNMP, database, canali) sono cifrate con questa chiave.
