REST API

Skrypty i inne systemy odczytują przez API JSON urządzenia, sprawdzenia, wykresy i problemy, potwierdzają problemy i planują konserwację.

Tokeny

Utwórz token w Moje konto → Tokeny API: nazwę i liczbę dni ważności. Jest wyświetlany tylko raz. Token działa w twoim imieniu, z twoją rolą (token obserwatora może tylko odczytywać); unieważnij go, gdy przestanie być potrzebny. Nieudane tokeny liczą się jak nieudane logowania i na pewien czas blokują adres.

Wysyłaj go w nagłówku; API nigdy nie akceptuje ciasteczka sesji konsoli:

curl -H "Authorization: Bearer wzat_…" https://monitor.example.com:8443/api/v1/status

Czasy są w formacie RFC 3339 (2026-11-01T22:00:00+01:00). Błędy mają postać {"error": "…"} z odpowiednim statusem HTTP. Zmiany trafiają do dziennika audytu z nazwą tokenu.
